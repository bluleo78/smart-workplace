## 노트
- 앱을 쓰던 브라우저에서 노트 공유 링크를 열면 「페이지를 찾을 수 없습니다」가 나던 문제를 고쳤습니다. 앱이 이번 버전으로 한 번 업데이트된 뒤부터 적용됩니다.
- 노트 사이드바에서 키보드로 페이지 순서를 바꿀 때 스크린리더가 영어 대신 한국어로 페이지 제목과 옮겨 갈 자리를 알려 줍니다.

## 이슈·채팅
- 한국 밖 시간대로 설정된 브라우저에서 이슈 채팅의 메시지 시각과 날짜 구분선이 서로 다른 날로 보이던 문제를 고쳤습니다. 메시지 시각도 한국 시간으로 보입니다.
- 이슈 보드에서 카드를 다른 열로 옮기면 잠깐 사라졌다 다시 나타나던 문제를 고쳤습니다.
- 이슈 코멘트에 반응을 한꺼번에 여러 번 눌러도 한 사람 20개, 한 코멘트 50종 제한을 넘지 않습니다.
- 개인 프로젝트에서는 AI 를 소유자로 올리거나 주인을 멤버로 내릴 수 없습니다. 이미 그렇게 바뀐 개인 프로젝트는 주인이 다시 소유자가 됩니다.

## 드라이브·노트
- 파일이나 노트 이미지가 올릴 수 있는 크기를 넘으면 어떤 파일이 몇 MB 까지 되는지 한국어로 알려 줍니다.

## 화면
- 코멘트·채팅 메시지·이슈 첨부를 지운 뒤, 반응을 달거나 취소한 뒤, 보드 카드나 드라이브 파일을 키보드로 옮긴 뒤, 홈 편집에서 위젯을 지운 뒤에도 키보드 포커스가 화면 맨 위로 빠지지 않고 그 자리 근처에 남습니다.
- 스크린리더가 이슈 코멘트 작성·수정 칸과 메시지 수정 칸을 각각 알맞은 이름으로 읽고, 「내 작업」과 모바일 보드의 탭을 그 탭 내용과 이어서 읽습니다.
- 노트 마크다운 소스와 SSO 관리자 동의 링크의 「복사」가 브라우저가 클립보드를 막은 환경에서도 다른 복사 버튼처럼 동작합니다.

## 설정·관리·보안
- 개인 API 토큰을 20개 모두 쓰고 있으면 발급 창 안에서 그 이유를 보여 주고, 안내 문구를 목록 버튼과 같은 「폐기」로 맞췄습니다.
- 구성원 추가, 역할 지정·변경, AI 추가·키 발급, AI 모델 자격 증명 저장은 웹에 로그인한 상태에서만 할 수 있습니다. 개인 API 토큰이나 AI 키로는 할 수 없습니다.
- 보안을 강화했습니다.
