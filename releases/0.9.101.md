## 이슈
- 이슈에 담당을 지정하기만 하면 시작 조건에 맞는 워크플로우가 바로 시작됩니다. 따로 시작 창을 열거나 체크박스를 켤 필요가 없습니다.
- 워크플로우 편집기 머리의 스위치로 워크플로우를 켜고 끌 수 있고, 처음 게시할 때 바로 켤 수 있습니다.
- 워크플로우 탭에서 그래프와 YAML 을 한 화면에서 바꿔 보며, 그래프 캔버스를 화면 높이까지 넓게 씁니다.
- 워크플로우 노드를 누르면 캔버스 옆 서랍에서 속성을 고치고, 빈 캔버스를 누르면 역할·시작 조건·검사 결과 같은 워크플로우 개요를 봅니다.
- 워크플로우 그래프에서 질문 답변 노드가 묻는 노드 옆에 놓여, 「개발 → 질문 → 답 → 다시 개발」 흐름이 곁가지 루프로 읽힙니다.
- 워크플로우 그래프에서 노드를 옮겨도 YAML 의 손대지 않은 줄 서식(정렬·주석 간격)이 그대로 남습니다.
- 이슈당 첨부를 20개까지 올릴 수 있고, 한도를 넘는 파일은 올리기 전에 알려 줍니다. 첨부 영역은 키보드로도 열 수 있습니다.
- 이슈 목록 보기 설정에 「끝난 이슈 아래로」가 생겨, 완료·취소된 이슈를 목록 맨 뒤로 모아 볼 수 있습니다.
- 이슈 상세의 하위·연결 이슈, 에픽 패널, 홈 이슈 위젯에서도 끝난 이슈가 흐림·취소선으로 보입니다.
- 두 사람이 이슈 본문·제목을 동시에 고쳐 충돌하면 그 자리에서 최신 내용을 보여 주고, 덮어쓸지 한 번 더 확인합니다. 앞서 저장한 사람의 글이 말없이 사라지지 않습니다.
- 하위 태스크의 유형을 태스크 등으로 바꿀 때 상위 연결이 끊기면 확인 창으로 먼저 알려 줍니다.
- 이슈 목록 「필터 지우기」를 검색 입력 직후에 눌러도 검색어가 되살아나지 않고, 마일스톤·에픽만 걸린 경우에도 단추가 보입니다.

## 메시지·코멘트
- 댓글·채팅에 쓴 이슈 키 링크가 완료·취소된 이슈면 취소선으로 보이고, 마우스를 올리면 상태를 알려 줍니다.
- 멘션 후보 목록이 갱신되는 사이 Enter 를 눌러도 엉뚱한 사람이 멘션되지 않고, Shift+Enter 는 줄바꿈, Esc 는 후보 창만 닫습니다.
- 대화 첫 화면의 빈 상태 안내 문구가 단어 중간에서 꺾이지 않습니다.

## AI
- AI 비서가 사용 한도에 걸리면 풀릴 때까지 자동 호출을 멈추고 비서 주인에게 알립니다. 실패가 회차마다 쌓이지 않습니다.
- 오래 걸리는 AI 작업이 일률 60초 제한으로 끊기지 않도록 작업 종류별로 실행 시간 한도를 나눴습니다.
- 「AI 현황」에서 여러 AI 작업이 겹쳐 돌 때 한도 초과 실패 사유가 다른 사유로 바뀌어 보이던 문제를 고쳤습니다.
