## Claude Code 플러그인
- 이슈에 「AI 개발팀」 라벨을 붙여 두면, 할 일이 없는 AI 개발자가 그 이슈를 하나씩 가져가 처리합니다. 가져간 AI 는 담당자에 더해지고(원래 사람 담당자는 그대로) 라벨은 떼어집니다. 여러 AI 가 동시에 가져가도 한 이슈는 한 AI 만 맡습니다. genia-works 플러그인을 최신 버전으로 업데이트하면 적용됩니다.

## 화면
- 브라우저 탭 제목에 지금 보고 있는 화면과 항목 이름이 보여, 탭을 여러 개 열어도 구분할 수 있습니다.
- 데스크톱에서 키보드로 화면을 열면 첫 Tab 에 「본문 바로가기」 링크가 나타나, 사이드바를 건너뛰고 바로 본문으로 갈 수 있습니다.
- 스크린리더로 노트·드라이브·메일·대화 화면에서도 지금 어느 화면인지 제목으로 알 수 있습니다.
- 이슈 제목·본문·코멘트·메시지 수정을 끝내거나 상태·우선순위를 고른 뒤, 드라이브 「새 폴더」·「이름 변경」 창을 닫은 뒤에 키보드 포커스가 화면 맨 위로 빠지지 않고 원래 자리로 돌아옵니다.

## 연락처
- 외부 연락처를 지우면 즐겨찾기와 사용자 그룹에서도 함께 빠집니다.
- 외부 연락처의 전화·소속·직함은 한 줄로 다듬고, 보이지 않는 글자만 넣으면 비운 것으로 저장해 소속 필터에 빈 항목이 생기지 않습니다.
- 사용자 그룹 두 개를 동시에 서로의 하위로 옮기면 두 그룹이 서로를 품던 문제를 고쳤습니다.

## 설정·계정·보안
- 개인 API 토큰과 AI 에이전트 API 키는 쓸 수 있는 것을 20개까지 발급할 수 있고, 토큰 목록에는 회수되거나 만료된 지 30일이 지난 토큰이 보이지 않습니다.
- 로그인이 필요할 때의 안내를 포함해, 역할 권한·지정, AI 비서 모델 이름 입력 등에서 알 수 없는 오류 대신 한국어 안내를 보여 주는 곳을 늘렸습니다. 워크스페이스에 속하지 않은 상태로 노트·드라이브를 열어도 오류 대신 빈 목록이 보입니다.
- 보안을 강화했습니다.
