# 용어

이 매뉴얼에서 쓰는 말을 가나다순으로 모았고, 영문으로 시작하는 말은 맨 뒤에 두었습니다. 같은 대상을 화면이 다르게 부르는 경우는 「화면 표기」 에 적었습니다.

| 용어 | 뜻 | 화면 표기·다루는 장 |
| --- | --- | --- |
| 감사 로그 | 워크스페이스에서 누가 언제 무엇을 했는지 남는 기록 | 설정 **감사 로그** · 17장 |
| 개인 비서 | 구성원 한 사람만 쓰는 AI 비서. 구성원이 자기 AI 서비스 토큰을 등록해 만듭니다 | 설정 **AI 비서** · 12장 |
| 공통 비서 | 개인 비서를 두지 않은 구성원의 AI 어시스턴트를 맡는 워크스페이스 AI. 관리자가 에이전트 하나를 지정합니다 | 에이전트 목록의 「공통」 배지 · 15장 |
| 관리자 | ADMIN 역할을 가진 구성원. **워크스페이스 관리** 와 **앱 설정** 을 씁니다 | 14장 |
| 구성원 | 워크스페이스에 등록된 사람. 본문에서는 「멤버」 대신 이 말을 씁니다 | **구성원** · 14장 |
| 노트 | 스페이스 안에 페이지를 쌓아 여럿이 함께 쓰는 문서 앱 | 레일 **노트** · 10장 |
| 담당자 | 이슈를 맡은 사람이나 AI | 이슈 상세 **담당자** · 4장·8장 |
| 대화 | 채널과 DM 으로 이야기하는 앱 | 레일 **대화**, 모바일 탭바 「채팅」 · 5장 |
| 드라이브 | 파일을 공간별로 모아 두는 앱 | 레일 **드라이브** · 9장 |
| 스레드 | 메시지 하나에 이어 단 답글 묶음 | 5장 |
| 스페이스 | 노트 페이지를 담는 공간. 나만 쓰는 「내 노트」 와 팀 스페이스가 있습니다 | 10장 |
| 에이전트 | 담당자로 지정되는 AI 구성원 | 담당자 목록의 「에이전트」 배지, 설정 **에이전트** · 4장·15장 |
| 역할 | 할 수 있는 일(권한)의 묶음. 구성원과 에이전트에게 줍니다 | 설정 **역할** · 14장 |
| 이력 | 이슈에서 바뀐 내용을 시간순으로 남긴 기록 | 이슈 상세 **활동** 의 **이력** 탭 · 8장 |
| 이슈 | 작업 관리에서 다루는 일 한 건 | 8장 |
| 코멘트 | 이슈에 남기는 글 | 이슈 상세 **활동** 의 **코멘트** 탭 · 8장 |
| 확인 카드 | AI 어시스턴트가 되돌리기 어려운 일을 하기 전에 띄우는 카드. **승인** 해야 실행됩니다 | 4장 |
| AI 비서 | 나를 맡는 AI(공통 비서 또는 개인 비서). 설정 화면 이름으로도 씁니다 | 설정 **AI 비서** · 12장 |
| AI 어시스턴트 | 화면 위 단추로 여는 AI 대화 패널 | 화면 위 **AI 어시스턴트** · 4장 |
| AI 위임 작업 | 내가 AI 에게 맡긴 이슈를 모아 보는 화면 | 작업 관리 사이드바 **AI 위임 작업** · 4장 |
| API 토큰 | 외부 AI 도구가 내 권한으로 접근할 때 쓰는 개인 토큰 | 설정 **API 토큰** · 12장 |
| DM | 한 사람(또는 몇 사람)과 나누는 대화 | 5장 |
| SSO | 회사 Microsoft 계정으로 로그인하는 방식 | 설정 **SSO** · 16장 |
