# 구성원과 역할

관리자는 **설정** 의 **워크스페이스 관리** 에서 워크스페이스에 들어올 사람을 등록하고, 사람마다 역할을 줍니다. 역할은 할 수 있는 일(권한)의 묶음입니다.

> **이 장에서 할 수 있는 일**
>
> - 구성원을 추가하고 찾습니다.
> - 구성원을 비활성화하거나 다시 활성화합니다.
> - 구성원에게 역할을 줍니다.
> - 역할을 만들고 권한을 고릅니다.

## 구성원을 찾는다

**워크스페이스 관리** 의 **구성원** 을 누르면 이 워크스페이스의 사람 구성원이 모두 보입니다.

![구성원 목록](shots/user/members-1.png){marks=admin!inside,search,list,create}

1. **워크스페이스 관리** 와 **앱 설정** 은 관리자에게만 보입니다.
2. **이름 또는 아이디로 검색...** 칸에 이름이나 아이디 일부를 넣어 찾습니다.
3. 행마다 이름·아이디와 상태(**활성**·**비활성**)가 보입니다. 행을 누르면 **사용자 상세** 가 열립니다.
4. 새 사람을 등록하려면 **구성원 추가** 를 누릅니다.

AI 구성원(에이전트)은 이 목록이 아니라 **에이전트** 화면에서 관리합니다(15장).

## 구성원을 추가한다

![구성원 추가 창](shots/user/members-2.png){crop=dialog marks=id,profile,password,role,more,submit}

1. **아이디 (로그인 ID)** 에 회사 계정 주소(이메일)를 넣습니다. 이 아이디로 로그인합니다.
2. **이메일 (선택)** 과 **이름** 을 넣습니다.
3. **초기 비밀번호** 를 넣습니다. 8자 이상이고 영문 대문자·소문자·숫자를 넣어야 합니다. 추가한 사람에게 따로 알려 줍니다.
4. **역할** 에서 **일반 구성원** 또는 **관리자** 를 고릅니다.
5. 여러 사람을 이어서 넣으려면 **계속 추가 (저장 후 다이얼로그 유지)** 를 켭니다.
6. **추가** 를 누릅니다.

SSO 를 켠 워크스페이스(16장)에서는 창에 **로그인 방식** 이 더 나옵니다. 처음 골라져 있는 **SSO 전용 (비밀번호 없음)** 으로 추가하면 그 사람은 Microsoft 로그인으로만 들어옵니다. **비밀번호** 를 고르면 **초기 비밀번호** 칸이 나옵니다.

## 구성원을 비활성화하고 역할을 준다

목록에서 사람을 누르면 **사용자 상세** 가 열립니다.

![사용자 상세](shots/user/members-3.png){crop=info+active+roles marks=info,active,roles}

1. **기본 정보** 에 아이디·이름·이메일·가입일·상태가 보입니다. 가입 정보는 구성원 본인만 바꿀 수 있습니다(12장).
2. **활성 상태** 의 스위치를 끄면 그 사람은 이 워크스페이스에 들어올 수 없습니다. 이미 로그인해 있던 사람도 다음 요청부터 바로 막힙니다. 다른 워크스페이스에는 영향이 없습니다.
3. **역할 할당** 에서 줄 역할을 고르고 **역할 저장** 을 누릅니다.

다시 활성화하면 역할과 참여하던 프로젝트가 그대로라 바로 이어서 씁니다. 비활성 구성원은 프로젝트 멤버로 새로 추가할 수 없습니다.

> **주의**
>
> 마지막 남은 활성 관리자(ADMIN)는 비활성화할 수도, ADMIN 역할을 뺄 수도 없습니다. 내 ADMIN 역할은 직접 뺄 수 없습니다.

## 역할과 권한을 관리한다

**워크스페이스 관리** 의 **역할** 에는 처음부터 있는 시스템 역할 셋(ADMIN·USER·AGENT)과 관리자가 만든 역할이 보입니다. 행을 누르면 **역할 상세** 가 열립니다.

![역할 상세 — 시스템 역할 USER](shots/user/members-4.png){crop=lock+perms marks=lock,info,perms}

1. 시스템 역할은 이름·설명·권한을 바꿀 수 없다는 안내가 보입니다. 관리자가 만든 역할만 고칩니다.
2. **역할 정보** 에서 **역할 이름** 과 **설명** 을 고치고 **저장** 을 누릅니다.
3. **권한 할당** 에서 이 역할이 할 수 있는 일을 고르고 **권한 저장** 을 누릅니다. 권한은 사용자·역할·권한 같은 묶음으로 나뉘어 있습니다.

새 역할은 **역할** 화면의 **역할 추가** 를 눌러 **역할 이름** 과 **설명 (선택)** 을 넣고 **생성** 을 누릅니다.

- 권한을 저장하면 이 역할을 가진 구성원 모두에게 바로 적용됩니다. 다시 로그인할 필요가 없습니다.
- 역할을 여러 개 가진 구성원은 각 역할의 권한을 모두 합쳐서 가집니다.
- 구성원은 역할과 관계없이 구성원 조회(member:read) 권한을 기본으로 가집니다.
- 워크스페이스 관리 화면은 ADMIN 역할이 있어야 열립니다. 다른 역할에 같은 권한을 줘도 이 화면들은 보이지 않습니다.
- 역할 정보와 권한은 저장 단추가 따로입니다. 체크만 바꾸고 나가면 반영되지 않습니다.

관리자가 만든 역할은 **역할** 목록 행 오른쪽의 휴지통 단추로 지웁니다.

구성원에게 줘 둔 역할은 지울 수 없습니다. 「n명의 사용자에게 할당된 역할은 삭제할 수 없습니다」 안내가 나오면 그 구성원들의 **사용자 상세** 에서 역할을 먼저 뺀 뒤 지웁니다.

관리자가 만든 역할은 상세에서 이름·설명과 권한을 모두 고칠 수 있습니다. 아래는 외부 협력사용으로 만든 역할 「PARTNER」 입니다.

![역할 상세 — 관리자가 만든 역할 PARTNER](shots/user/members-5.png){crop=area marks=info,perms}

1. **역할 정보** 에서 **역할 이름** 과 **설명** 을 고치고 **저장** 을 누릅니다.
2. **권한 할당** 에서 권한을 고르고 **권한 저장** 을 누릅니다.
