# 로그인·앱 설정

관리자는 구성원이 Microsoft 계정으로 로그인하게 하고(SSO), 작업 관리와 노트 앱에서 워크스페이스 전체에 적용되는 설정을 정합니다.

> **이 장에서 할 수 있는 일**
>
> - Microsoft 계정 로그인(SSO)을 켜고 끕니다.
> - 이슈 관계 유형을 팀이 쓰는 말로 정합니다.
> - 노트 외부 공유를 허용하거나 막고, 공유 중인 페이지를 정리합니다.

## Microsoft 계정 로그인을 켠다

**워크스페이스 관리** 의 **SSO** 를 누릅니다.

![SSO 로그인 설정](shots/user/workspace-settings-1.png){crop=section+toggle marks=toggle@l}

1. **SSO 로그인 사용** 을 켭니다. 켜면 구성원이 로그인 화면의 Microsoft 로그인(2장)으로 들어올 수 있고, 비밀번호 없는 「SSO 전용」 구성원을 등록할 수 있습니다.

그 아래 **관리자 동의 링크** 를 **복사** 해 회사 Entra(Microsoft 365) 관리자에게 전달하고, 한 번 승인받습니다. 승인 전에는 구성원이 "관리자 승인 필요" 오류로 로그인하지 못할 수 있습니다.

- SSO 로 들어올 사람은 먼저 구성원으로 등록돼 있어야 합니다(14장). 처음 로그인할 때 계정을 새로 만들지 않습니다.
- 구성원 아이디가 회사 Microsoft 로그인 주소와 같아야 연결됩니다. 대소문자는 가리지 않습니다.
- 다른 회사에서 게스트로 초대된 Microsoft 계정으로는 로그인할 수 없습니다.
- 켜도 비밀번호가 있는 구성원은 지금처럼 비밀번호로도 로그인할 수 있습니다.

> **주의**
>
> SSO 를 끄면 SSO 로 로그인해 있던 사람은 세션이 갱신될 때(최대 30분) 이 워크스페이스를 더 쓸 수 없습니다. 비밀번호 없는 SSO 전용 구성원이 있으면 끄기 전에 확인 창이 한 번 더 뜹니다.

## 이슈 관계 유형을 정한다

**앱 설정** 의 **작업 관리** 에서 이슈 사이 관계(8장)의 종류를 정합니다. 관계 유형은 워크스페이스의 모든 프로젝트에 같이 쓰입니다.

![이슈 관계 유형](shots/user/workspace-settings-2.png){crop=table+create marks=table,create,hide}

1. 표에 관계 유형마다 이름, 이 이슈 쪽과 상대 쪽에 보이는 말, 구분, 쓰는 곳(걸린 관계 수)이 보입니다.
2. **관계 유형 추가** 를 누르면 이름, 방향(**방향 있음**·**방향 없음 (양쪽 같은 말)**), 두 이슈에 보이는 말을 넣는 창이 열립니다. 아래 **미리보기** 로 이슈 화면에 어떻게 보이는지 확인하고 **추가** 를 누릅니다.
3. **숨기기** 를 누르면 그 유형으로 새 관계를 걸 수 없게 됩니다. 이미 걸린 관계는 그대로 보입니다.

- 「차단」 만 블로커 표시·차단 필터·타임라인 화살표에 반영됩니다. 다른 유형은 이슈 화면에 보여 주기만 합니다.
- 기본 유형은 이름과 말을 바꾸거나 지울 수 없습니다. 「차단」 말고는 숨길 수 있습니다.
- 이름과 말은 언제든 바꿀 수 있고, 이미 걸린 관계의 표시도 함께 바뀝니다. 방향은 걸린 관계가 없을 때만 바꿀 수 있습니다.

> **경고**
>
> 쓰이는 유형을 지울 때 「관계도 함께 삭제」를 고르면 그 유형으로 걸린 관계와 외부 링크가 모두 사라지고 되돌릴 수 없습니다.

## 노트 외부 공유를 관리한다

**앱 설정** 의 **노트** 에서 노트 페이지의 외부 공유를 정하고, 워크스페이스에서 공유 중인 페이지를 모아 봅니다.

![노트 공유 설정](shots/user/workspace-settings-3.png){crop=toggle+list marks=toggle,list}

1. **외부 공유 허용** 을 켜 두면 구성원이 노트 페이지를 로그인 없이 볼 수 있는 링크로 공유할 수 있습니다(보기만, 10장). 끄면 지금 있는 외부 링크가 모두 바로 막히고, 다시 켜도 되살아나지 않습니다.
2. **공유 중인 페이지** 에는 워크스페이스 전체에서 링크로 공유 중인 노트 페이지가 모입니다. 페이지 제목·만든 사람으로 찾고, 범위·스페이스로 거르고, 여러 개를 골라 한 번에 공유를 해제합니다.
