# 연락처

연락처는 워크스페이스 구성원과 거래처 같은 외부 사람을 한 목록에서 찾는 곳입니다. 외부 연락처는 나만 보거나 팀과 함께 볼 수 있고, 조직도와 내 그룹으로 사람을 묶어 봅니다.

> **이 장에서 할 수 있는 일**
>
> - 구성원과 외부 연락처를 찾아 상세 정보를 봅니다.
> - 외부 연락처를 추가하고 고칩니다.
> - 자주 찾는 사람을 즐겨찾기에 둡니다.
> - 조직도와 내 그룹으로 사람을 묶어 봅니다.

## 연락처를 찾아 본다

레일의 **연락처** 를 누르면 모든 연락처가 이름순으로 보입니다. 행을 누르면 오른쪽에 상세 정보가 열립니다.

![연락처 — 외부 연락처를 고른 모습](shots/user/contacts-1.png){marks=views!inside,groups@r,search,row@r,detail@r,create}

1. **전체**·**멤버**·**외부**·**즐겨찾기** 로 보이는 연락처를 거릅니다.
2. **조직도** 와 **내 그룹** 에서 그룹을 누르면 그 그룹의 사람만 보입니다(아래 「그룹으로 묶어 본다」).
3. **이름·이메일 검색** 칸에 이름이나 이메일 일부를 넣어 찾습니다.
4. 목록에서 사람을 누릅니다. 행 왼쪽의 **멤버**·**외부** 표시로 구성원인지 외부 사람인지 구분합니다. 행에 마우스를 올리면 나오는 별을 누르면 즐겨찾기에 둡니다.
5. 오른쪽에 이메일·전화·소속·직책·메모가 보입니다. 외부 연락처는 이름 아래에 **외부 연락처 · 개인** 또는 **외부 연락처 · 공유** 가 붙고, **수정**·**삭제** 단추가 있습니다.
6. 외부 사람을 추가하려면 **새 외부 연락처** 를 누릅니다(아래 「외부 연락처를 추가한다」).

## 외부 연락처를 추가한다

![새 외부 연락처 창](shots/user/contacts-2.png){crop=dialog marks=name,fields,scope,save@r}

1. **이름** 을 넣습니다. 이름은 꼭 넣어야 합니다.
2. **이메일**·**전화**·**소속**·**직책**·**메모** 를 필요한 만큼 넣습니다.
3. **공개 범위** 에서 **개인**(나만 봄) 또는 **공유**(워크스페이스 구성원이 함께 봄)를 고릅니다.
4. **저장** 을 누릅니다.

## 그룹으로 묶어 본다

- **조직도** 는 워크스페이스가 함께 쓰는 부서 구조입니다. 관리자만 「+」 로 부서를 만들고 고칩니다. 구성원은 부서를 눌러 그 부서 사람을 봅니다.
- **내 그룹** 은 나만 쓰는 사람 묶음입니다. 「+」 로 그룹을 만들고 사람을 넣습니다. 내 그룹은 채널 멤버를 추가할 때(5장)나 일정 참석자를 고를 때(7장) 한꺼번에 고르는 데 씁니다.

## AI 와 함께 — 연락처 정리를 맡긴다

화면 위 **AI 어시스턴트** 에게 「페이링크 담당자 연락처 알려 줘」처럼 요청하면 연락처를 찾아 답합니다. 연락처를 바꾸는 요청은 종류마다 처리 방식이 다릅니다.

| 요청 | AI 가 하는 방식 |
| --- | --- |
| 연락처·그룹 찾기 | 읽기만 합니다 |
| 외부 연락처 만들기·고치기, 즐겨찾기, 그룹 만들기·고치기, 그룹에 사람 넣고 빼기 | 직접 실행합니다 |
| 외부 연락처 삭제, 그룹 삭제 | 확인 카드를 띄웁니다. **승인** 해야 실행됩니다 |
