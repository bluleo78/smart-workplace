# 모바일에서 쓰기

휴대폰 브라우저로 Gen:iA Works 를 열면 화면 아래에 탭바가 있는 모바일 화면으로 바뀝니다. 데스크톱 레일의 앱은 탭바와 **앱** 화면에 나뉘어 놓입니다. 탭바에 둘 앱과 순서는 사람마다 고릅니다.

> **이 장에서 할 수 있는 일**
>
> - 탭바와 **앱** 화면에서 앱을 엽니다.
> - 자주 쓰는 앱을 탭바에 고정하고 순서를 바꿉니다.
> - 푸시 알림을 눌러 해당 화면으로 바로 갑니다.
> - 지금 보는 화면의 링크를 복사하거나 다른 앱으로 보냅니다.

## 앱을 연다

탭바 맨 오른쪽 **앱** 을 누르면 모든 앱이 한 화면에 보입니다.

![앱 화면과 탭바](shots/user/mobile-1.png){marks=coach,grid,edit,tabbar!inside}

1. 처음에는 **길게 눌러 탭바에 고정** 안내가 보입니다. 오른쪽 X 를 누르면 닫힙니다.
2. 앱을 누르면 그 앱이 열립니다. 오른쪽 위에 핀 표시가 붙은 앱은 탭바에 고정된 앱입니다.
3. **탭바 순서 편집** 을 누르면 탭바에 둘 앱과 순서를 고르는 화면이 열립니다(아래 「탭바 순서를 바꾼다」).
4. 탭바에는 홈·채팅·메일·캘린더·드라이브 같은 고정한 앱과, 가운데 「AI」, 맨 오른쪽 **앱** 이 놓입니다. 안 읽은 대화가 있으면 앱 위에 숫자가 붙습니다.

가운데 「AI」 를 누르면 **AI 어시스턴트** 가 화면 아래에서 올라옵니다(4장). 설정은 **앱** 화면의 **설정** 에서 엽니다. 모바일의 설정 목록에는 데스크톱과 같은 항목이 있습니다(12장, 관리자는 14~17장).

## 앱을 탭바에 고정한다

앱을 길게 누르면 그 앱의 메뉴가 열립니다. 이미 고정된 앱은 핀 표시를 눌러도 열립니다.

![고정된 앱의 메뉴](shots/user/mobile-3.png){crop=row+tile+menu marks=tile,menu}

1. 앱을 길게 누르거나, 고정된 앱의 핀 표시를 누릅니다.
2. 고정된 앱이면 **다른 앱으로 교체** 로 이 자리에 둘 다른 앱을 고릅니다. 고정되지 않은 앱이면 **탭바에 고정** 이 나오고, 탭바가 꽉 찼으면 바꿀 탭을 고릅니다. **열기** 는 그 앱을 엽니다.

## 탭바 순서를 바꾼다

**앱** 화면의 **탭바 순서 편집** 을 누르면 **탭바 순서 편집** 화면이 열립니다.

![탭바 순서 편집](shots/user/mobile-2.png){marks=intro!inside,slots@l,add!inside,save}

1. 가운데 「AI」 와 맨 오른쪽 **앱** 은 고정입니다. 나머지 5칸을 고릅니다.
2. 탭바에 놓인 앱마다 위·아래 화살표로 순서를 바꾸고, 「−」 로 탭바에서 뺍니다.
3. **추가할 수 있는 앱** 에서 「+」 를 눌러 탭바에 넣습니다. 탭바가 꽉 찼으면 하나를 빼야 넣을 수 있습니다.
4. **저장** 을 누르면 탭바가 바뀝니다.

탭바 설정은 지금 쓰는 브라우저에만 저장됩니다. 다른 휴대폰이나 브라우저에서는 따로 정합니다.

## 푸시 알림에서 바로 연다

**설정** → **알림** 에서 **이 기기에서 푸시 받기** 를 켜면(12장) 앱을 닫아도 알림이 휴대폰으로 옵니다. 알림을 누르면 그 알림의 화면이 바로 열립니다. 로그인이 풀려 있으면 로그인 화면이 먼저 나오고, 로그인하면 원래 가려던 화면으로 이어집니다. 다른 워크스페이스의 알림이면 그 워크스페이스로 바꾼 뒤 엽니다.

> **참고**
>
> iPhone·iPad 는 홈 화면에 추가한 앱에서만 알림을 받습니다. Safari 의 공유 단추에서 「홈 화면에 추가」 를 누른 뒤, 홈 화면의 Gen:iA 앱에서 **이 기기에서 푸시 받기** 를 켭니다.

## 지금 보는 화면의 링크를 보낸다

이슈·노트·드라이브 파일과 폴더·일정·메일을 연 화면의 위쪽 **공유** 단추(위 화살표가 있는 상자 모양)를 누르면 공유 시트가 열립니다. 시트 맨 위에 대상 이름이 보입니다.

1. **링크 복사** 로 그 화면의 링크를 복사합니다.
2. **다른 앱으로 보내기** 로 메시지·메일 같은 다른 앱에 링크를 보냅니다. 휴대폰이 공유 기능을 지원할 때만 보입니다.
3. 이슈에서는 **키 복사** 로 이슈 키만 복사합니다.
4. 노트와 드라이브 파일에서는 **외부 공유 링크…** 로 외부 공유 창을 엽니다(9장·10장).
