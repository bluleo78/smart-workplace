# 로그인과 화면 구조

Gen:iA Works 에 로그인하는 방법과, 로그인한 뒤 보이는 화면의 구성을 설명합니다. 레일·알림·워크스페이스·사용자 메뉴는 어느 앱에서나 같은 자리에 있습니다.

> **이 장에서 할 수 있는 일**
>
> - 아이디와 비밀번호로, 또는 Microsoft 계정으로 로그인합니다.
> - 화면의 구성(레일, 알림, 워크스페이스, 사용자 메뉴)을 봅니다.
> - 레일을 펼쳐 앱 이름을 봅니다.
> - 알림을 확인하고 읽음으로 표시합니다.
> - 워크스페이스를 바꾸고, 로그아웃합니다.
> - 지금 보는 이슈·노트·파일·일정·메일의 링크를 복사합니다.

## 로그인한다

![로그인 화면](shots/user/login-and-layout-1.png){crop=card marks=username,password,submit}

1. **아이디** 칸에 아이디를 입력합니다. 아이디는 보통 회사 이메일 주소입니다.
2. **비밀번호** 칸에 비밀번호를 입력합니다. 칸 오른쪽 눈 모양 단추를 누르면 입력한 글자를 볼 수 있습니다.
3. **로그인** 을 누릅니다. 홈이 열립니다.

로그인이 안 되면 칸 아래에 나온 문구로 원인을 구분합니다.

| 문구 | 뜻 |
| --- | --- |
| **아이디 또는 비밀번호가 올바르지 않습니다.** | 아이디나 비밀번호가 틀렸습니다 |
| **접속 가능한 워크스페이스가 없습니다. 관리자에게 문의하세요.** | 아이디·비밀번호는 맞지만 들어갈 수 있는 워크스페이스가 없습니다. 관리자가 워크스페이스에서 나를 비활성화한 경우에도 이 문구가 나옵니다 |
| **로그인 시도 횟수를 초과하였습니다. 잠시 후 다시 시도해 주세요.** | 비밀번호를 연달아 틀려 계정이 잠겼습니다(아래 주의) |

> **주의**
>
> 비밀번호를 5번 연달아 틀리면 계정이 잠깁니다. 잠긴 동안에는 맞는 비밀번호를 넣어도 로그인되지 않고, 마지막으로 틀린 때부터 15분이 지나면 다시 로그인할 수 있습니다. 비밀번호가 기억나지 않으면 더 시도하지 말고 관리자에게 문의합니다.

비밀번호를 스스로 다시 정하는 화면은 없습니다. 비밀번호를 잊었으면 워크스페이스 관리자에게 문의합니다.

로그인은 브라우저에 기억됩니다. 창을 새로 고치거나 다시 열어도 로그인 화면을 거치지 않습니다. 로그인을 끝내려면 아래 「사용자 메뉴로 로그아웃한다」를 따릅니다.

### 소속 워크스페이스가 둘 이상일 때

한 계정이 여러 워크스페이스에 속해 있으면, 로그인한 뒤 **워크스페이스 선택** 화면이 나옵니다. **접속할 워크스페이스를 선택하세요.** 안내 아래 목록에서 들어갈 워크스페이스를 누릅니다. 들어간 뒤에도 레일의 워크스페이스 메뉴로 바꿀 수 있습니다(아래 「워크스페이스를 바꾼다」).

## Microsoft 계정으로 로그인한다

회사가 Microsoft 로그인을 설정했으면 로그인 화면 아래에 **Microsoft 계정으로 로그인** 이 보입니다.

![Microsoft 계정으로 로그인 단추](shots/user/login-and-layout-1.png){crop=card marks=microsoft}

1. **Microsoft 계정으로 로그인** 을 누릅니다. Microsoft 로그인 화면으로 넘어갑니다.
2. Microsoft 화면에서 회사 계정으로 로그인합니다. 끝나면 **로그인 중…** 이 잠시 보인 뒤 홈이 열립니다.

Microsoft 계정은 Gen:iA Works 계정과 짝이 맞아야 들어갈 수 있습니다. 처음 로그인할 때 Microsoft 계정의 로그인 이름(회사 이메일 주소)과 같은 아이디의 Gen:iA Works 계정을 찾아 둘을 연결합니다. 그 워크스페이스에서 관리자가 Microsoft 로그인을 켜 두어야 합니다(16장).

로그인이 안 되면 로그인 화면 위에 이유가 나옵니다.

| 문구 | 뜻 |
| --- | --- |
| **등록되지 않은 Microsoft 계정입니다. 관리자에게 등록을 요청하세요.** | 같은 아이디의 계정이 없거나, 그 계정이 Microsoft 로그인을 켠 워크스페이스에 속해 있지 않습니다 |
| **조직 관리자의 앱 승인이 필요합니다.** | 회사의 Microsoft 관리자가 Gen:iA Works 앱을 아직 승인하지 않았습니다 |
| **로그인 처리 중 문제가 발생했습니다. 다시 시도해 주세요.** | 처리 중 오류가 났습니다. 다시 시도합니다 |

Microsoft 로그인은 됐지만 들어갈 워크스페이스가 없으면 **로그인할 수 없습니다** 화면이 나옵니다. **로그인 화면으로** 를 눌러 돌아가고 관리자에게 문의합니다.

## 계정이 없을 때

구성원 계정은 관리자가 만들어 아이디와 처음 비밀번호를 알려 줍니다(14장). 스스로 가입하는 화면은 서비스를 처음 설치할 때 첫 계정을 만드는 데만 쓰이고, 그 뒤에는 잠깁니다. 잠긴 뒤 회원가입 주소로 들어가면 아래 안내가 나옵니다.

![회원가입이 잠긴 안내](shots/user/login-and-layout-2.png){crop=card}

**회원가입이 비활성화되어 있습니다. 관리자에게 문의하세요.** 가 보이면 관리자에게 계정을 요청합니다. **로그인** 을 누르면 로그인 화면으로 돌아갑니다. 가입이 잠긴 동안에는 로그인 화면에도 회원가입 링크가 없습니다.

## 화면 구성을 본다

로그인하면 홈이 열립니다. 화면 왼쪽의 좁은 띠가 레일이고, 나머지가 지금 연 앱의 화면입니다.

![로그인한 화면 — 왼쪽 레일과 앱 화면](shots/user/login-and-layout-3.png){marks=apps@r,assistant,workspace,user}

1. 레일 위쪽에 앱이 있습니다. 위에서부터 **홈**·**대화**·**메일**·**캘린더**·**작업 관리**·**드라이브**·**노트**·**연락처**·**설정** 순서입니다. 아이콘에 마우스를 올리면 이름이 보이고, 누르면 그 앱이 열립니다. 안 읽은 대화·메일이 있으면 아이콘 위에 수가 붙습니다.
2. 화면 위 가운데의 **AI 어시스턴트** 를 누르면 오른쪽에 AI 어시스턴트 패널이 열립니다. 키보드로는 Mac 에서 Command+K, Windows 에서 Ctrl+K 로 열고 닫습니다. 쓰는 법은 [4장](04-ai-collaboration.md)에 있습니다.
3. 레일 아래쪽 첫 칸은 지금 들어와 있는 워크스페이스입니다. 이름 첫 글자가 보입니다.
4. 맨 아래 동그라미는 내 계정입니다. 누르면 사용자 메뉴가 열립니다.

워크스페이스와 내 계정 사이의 종 모양은 **알림** 입니다. 안 읽은 알림 수가 붙습니다(아래 「알림을 확인한다」). **AI 어시스턴트** 단추는 내가 쓸 수 있는 AI 비서가 있을 때만 보입니다. 보이지 않으면 관리자에게 문의합니다.

> **참고**
>
> 모든 앱을 한꺼번에 찾는 검색 칸은 없습니다. **대화**·**메일**·**작업 관리**·**드라이브**·**노트**·**연락처** 처럼 앱마다 그 화면 안에 검색 칸이 있습니다. 앱별 검색은 각 앱의 장에서 설명합니다.

## 레일을 펼친다

레일은 처음에 아이콘만 보입니다. 펼치면 앱 이름이 함께 보입니다.

![펼친 레일 — 앱 이름이 함께 보입니다](shots/user/login-and-layout-4.png){crop=toggle+apps marks=toggle,apps}

1. 레일 맨 위의 Gen:iA Works 표시를 누릅니다. 레일이 펼쳐지고 로고가 보입니다. 다시 누르면 접힙니다.
2. 이름을 보고 앱을 누릅니다.

펼침 상태는 브라우저에 기억되어 다음에 열어도 그대로입니다.

## 알림을 확인한다

누가 내 이슈에 코멘트를 남기거나 나를 담당자로 지정하면 알림이 옵니다.

![알림 목록 — 레일의 알림을 누르면 열립니다](shots/user/login-and-layout-5.png){crop=panel+trigger marks=trigger@br,item,markAll}

1. 레일의 **알림** 을 누릅니다. 종 위의 빨간 숫자는 안 읽은 알림 수입니다. 최근 알림 목록이 열립니다. 안 읽은 알림은 오른쪽에 파란 점이 있습니다.
2. 알림을 누릅니다. 알림이 가리키는 화면(이슈 등)으로 넘어가고, 그 알림은 읽음이 됩니다.
3. 목록을 다 확인했으면 **모두 읽음** 을 누릅니다. 안 읽은 알림 수가 사라집니다.

목록을 아래로 내리면 이전 알림이 이어서 나옵니다. 알림이 하나도 없으면 **새 알림이 없습니다** 가 보입니다. 어떤 알림을 받을지는 **설정** 의 **알림** 에서 정합니다(12장).

> **참고**
>
> 휴대폰에서는 알림이 별도 화면으로 열립니다(13장). 컴퓨터에서 그 화면 주소로 들어오면 홈으로 돌아가며 알림 목록이 열립니다.

## 지금 보는 화면의 링크를 복사한다

설치한 앱(데스크톱 앱·홈 화면 앱)에는 주소창이 없습니다. 이슈·노트·드라이브 파일과 폴더·일정·메일을 연 화면에서는 오른쪽 위 링크 단추로 그 화면의 링크를 복사해 다른 사람에게 전합니다.

1. 오른쪽 위 **링크 복사**(사슬 모양 단추)를 누르면 링크가 복사되고 「링크를 복사했어요」 가 보입니다. 알림의 **채팅으로 보내기** 를 누르면 같은 링크를 앱 안 채널·DM·이슈 댓글로 보냅니다(아래 「링크를 채팅·이슈로 보낸다」).
2. 단축키 ⇧⌘,(Windows 는 Ctrl+Shift+,)도 같은 일을 합니다. 입력칸에 글을 쓰는 중에도 됩니다.
3. 이슈에서는 옆 점 세 개 단추의 **키 복사**(⌘. · Windows 는 Ctrl+.)로 「WP-12」 같은 이슈 키만 복사합니다.
4. 점 세 개 단추의 **채팅·이슈로 보내기…** 도 같은 보내기 창을 엽니다.
5. 설치한 앱에서는 점 세 개 단추에 **브라우저에서 열기** 가 있어, 지금 화면을 브라우저 탭으로 엽니다.

> **참고**
>
> 노트·드라이브의 **공유** 는 스페이스 밖 사람에게 여는 외부 공유 링크를 만드는 일이라 **링크 복사** 와 다릅니다. **링크 복사** 로 복사한 링크는 그 화면을 볼 수 있는 구성원만 엽니다. 휴대폰에서는 위쪽 **공유** 단추로 엽니다(13장).

## 링크를 채팅·이슈로 보낸다

복사한 링크를 붙여 넣을 곳이 앱 안이라면 **채팅·이슈로 보내기** 창에서 바로 보냅니다. 받는 사람에게는 채팅에 붙인 링크와 같은 카드로 보이고, 카드를 누르면 같은 화면이 열립니다.

1. 「링크를 복사했어요」 알림의 **채팅으로 보내기**, 또는 점 세 개 단추의 **채팅·이슈로 보내기…** 를 누릅니다. 휴대폰에서는 위쪽 **공유** 단추의 시트에서 고릅니다(13장).
2. 창 위 검색칸에 채널 이름·사람 이름·이슈 제목이나 키(WP-12)를 입력해 받는 곳을 찾습니다. 검색어가 없으면 최근에 보낸 곳과 내 채널이 보입니다.
3. 받는 곳을 누르면 보낼 링크의 카드가 보입니다. 다른 곳으로 바꾸려면 **바꾸기** 를 누릅니다.
4. 필요하면 「함께 보낼 말 (선택)」 칸에 한마디를 적고 **보내기** 를 누릅니다. 채널은 그 채널에, 사람은 그 사람과의 DM 에, 이슈는 그 이슈의 코멘트로 올라갑니다.
5. 보낸 뒤 알림의 **보기** 를 누르면 보낸 곳으로 갑니다.

> **참고**
>
> 일정·메일·드라이브 폴더 링크는 아직 카드 없이 누를 수 있는 링크로 보입니다. 받는 사람이 그 대상을 볼 수 없으면 카드에 「볼 수 없는 …」 이 보입니다.

## 워크스페이스를 바꾼다

여러 워크스페이스에 속해 있으면 로그아웃하지 않고 다른 워크스페이스로 옮길 수 있습니다.

![워크스페이스 메뉴](shots/user/login-and-layout-6.png){crop=menu+trigger marks=trigger,menu}

1. 레일 아래쪽의 워크스페이스 표시를 누릅니다. **워크스페이스** 메뉴가 열립니다.
2. 옮길 워크스페이스를 누릅니다. 지금 들어와 있는 워크스페이스에는 체크 표시가 있습니다.

속한 워크스페이스가 하나뿐이면 목록에 그 하나만 흐리게 보이고 누를 수 없습니다.

## 사용자 메뉴로 로그아웃한다

레일 맨 아래의 내 계정 동그라미를 누르면 사용자 메뉴가 열립니다. 메뉴 맨 위에 내 이름이 보입니다.

![사용자 메뉴](shots/user/login-and-layout-7.png){crop=menu+trigger marks=profile@r,whatsNew@r,theme@r,logout@r}

1. **프로필** 을 누르면 이름·사진 등을 바꾸는 화면이 열립니다(12장).
2. **새 소식** 을 누르면 최근 업데이트 내용이 열립니다. 오른쪽에 지금 쓰는 버전이 보이고, 아직 안 본 새 소식이 있으면 파란 점이 붙습니다.
3. **테마 전환** 을 누르면 밝은 화면과 어두운 화면이 바뀝니다.
4. **로그아웃** 을 누릅니다. 로그인 화면으로 돌아갑니다.

> **주의**
>
> 여러 사람이 쓰는 컴퓨터에서는 일이 끝나면 반드시 로그아웃합니다. 창을 닫기만 하면 로그인이 남아 다음 사람이 내 계정으로 들어올 수 있습니다.
