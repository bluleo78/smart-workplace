# 작업 관리

작업 관리는 팀의 일을 이슈로 나눠 담당자·상태·마감과 함께 관리하는 앱입니다. 이슈는 프로젝트에 모이고, 사이클(스프린트)·마일스톤·버전으로 묶어 진행을 봅니다. 담당자에는 사람과 AI 를 함께 지정할 수 있습니다(4장).

> **이 장에서 할 수 있는 일**
>
> - 프로젝트 목록에서 프로젝트를 고릅니다.
> - 이슈를 목록·보드로 보고, 거르고, 묶어 봅니다.
> - 새 이슈를 만들고 상태·담당자·일정을 바꿉니다.
> - 내 작업에서 내가 맡은 이슈를 한곳에서 봅니다.
> - 사이클·버전·타임라인으로 진행을 봅니다.

## 프로젝트를 고른다

레일의 **작업 관리** 를 누르고 사이드바의 **전체 보기** 를 누르면 내가 속한 프로젝트가 모두 보입니다.

![프로젝트 목록](shots/user/work-1.png){marks=nav@br,create,row!inside}

1. 사이드바에서 **내 작업**·**AI 위임 작업**, 개인 프로젝트, 팀 프로젝트로 이동합니다.
2. 새 프로젝트를 만들려면 **새 프로젝트** 를 누릅니다.
3. 프로젝트 행을 누르면 그 프로젝트의 이슈 목록이 열립니다. 행에는 진행률(완료한 이슈 비율), 멤버, 최근 활동 시각이 보입니다.

**개인 작업** 은 나만 쓰는 개인 프로젝트로, 처음부터 있습니다. 팀 프로젝트는 멤버로 추가된 사람만 봅니다. 자주 여는 프로젝트는 행 오른쪽의 별을 눌러 즐겨찾기에 둡니다.

## 이슈를 목록으로 본다

프로젝트를 열면 이슈가 사이클별로 묶인 목록이 보입니다.

![프로젝트 이슈 목록](shots/user/work-2.png){marks=pages,create,filters,view@bl,group}

1. 머리의 **사이클**·**버전**·**타임라인**·**설정** 으로 프로젝트의 다른 화면을 엽니다(아래 「진행을 본다」).
2. **새 태스크** 로 새 이슈를 만듭니다(아래 「새 이슈를 만든다」).
3. **태스크 검색** 칸과 **담당자**·**상태**·**유형**·**라벨**·**우선순위** 로 목록을 거릅니다. **더 보기** 를 누르면 거를 항목을 더 고를 수 있습니다.
4. 오른쪽 단추로 목록 보기와 보드 보기를 바꿉니다.
5. 묶음 머리에는 사이클 이름과 기간, 남은 날, 진행률이 보입니다. 묶음 머리를 누르면 접고 펼칩니다.

**그룹** 에서 묶는 기준을 **사이클**·**상태**·**담당자**·**우선순위**·**에픽** 중에서 고릅니다. **열** 로 목록에 보일 칸을 고르고, **완료 모두 보기** 를 켜면 끝난 이슈도 보입니다. 행 왼쪽 체크로 여러 이슈를 골라 한꺼번에 옮기거나 바꿀 수 있습니다.

지금 거른 조건은 **뷰 저장** 으로 이름을 붙여 저장해 두고 다시 불러옵니다. **에픽** 을 누르면 오른쪽에 에픽 목록이 열립니다.

## 이슈를 보드로 본다

![보드 보기 — 상태별 열](shots/user/work-3.png){marks=view,column@tr,card@r}

1. 목록 오른쪽의 보드 단추를 누릅니다.
2. 상태마다 열이 하나씩 놓입니다. 열 머리에 상태 이름과 이슈 수가 보입니다.
3. 카드를 다른 열로 끌어 놓으면 상태가 바뀝니다. 카드를 누르면 이슈가 열립니다.

## 새 이슈를 만든다

**새 태스크** 를 누르면 **새 이슈** 창이 열립니다.

![새 이슈 창 — 제목을 넣은 모습](shots/user/work-4.png){crop=dialog marks=title,body,fields,submit@r}

1. **제목** 을 넣습니다. 제목은 꼭 넣어야 합니다.
2. **본문** 에 내용을 씁니다. 이미지는 붙여넣거나 끌어다 놓습니다.
3. **유형**·**우선순위**·**시작일**·**마감일** 을 고릅니다.
4. **생성** 을 누릅니다.

담당자·라벨·사이클은 이슈를 만든 뒤 이슈 상세 화면에서 정합니다.

## 이슈를 열어 진행한다

목록이나 보드에서 이슈를 누르면 이슈 상세 화면이 열립니다.

![이슈 상세 화면](shots/user/work-5.png){marks=path,title,children,activity,rail@l}

1. 맨 위에 프로젝트 → 상위 에픽 → 이 이슈의 경로가 보입니다. 오른쪽 위 **링크 복사** 는 이 이슈의 링크를 복사하고, 그 옆 점 세 개 단추의 **키 복사** 는 이슈 키를 복사합니다(2장). **채팅** 은 이 이슈의 대화를, **구독 중** 은 구독 상태와 구독자 수를, **삭제** 는 이슈 삭제를 엽니다.
2. 제목 옆 연필을 누르면 제목을 고칩니다. 아래에 유형이 보입니다.
3. **본문** 아래에 파일을 첨부하고, **하위 태스크** 에 제목을 넣고 Enter 를 눌러 하위 태스크를 만듭니다.
4. **활동** 의 **코멘트** 탭에서 코멘트를 남기고, **이력** 탭에서 바뀐 내용을 시간순으로 봅니다.
5. 오른쪽 **상태·담당** 과 **일정** 에서 상태·우선순위·담당자, 시작일·마감일·사이클·마일스톤을 바꿉니다.

코멘트에서 「@」 를 입력하고 이름을 이어 쓰면 동료를 멘션합니다. 멘션된 동료에게는 알림이 갑니다.

코멘트에 `WP-12` 처럼 내가 속한 프로젝트의 이슈 키를 쓰면 그 이슈로 가는 링크가 됩니다. 링크에 마우스를 올리면(휴대폰은 누르면) 제목·상태·담당자가 미리 보입니다. 자세한 내용은 5장을 봅니다.

### 상태를 바꾼다

![상태 목록](shots/user/work-6.png){crop=status+list marks=status,list@l}

1. **상태·담당** 의 **상태** 칸을 누릅니다.
2. **할 일**·**진행 중**·**완료**·**취소** 중에서 고릅니다. 고르는 즉시 저장됩니다.

프로젝트에 따라 상태가 더 있을 수 있습니다. 상태는 프로젝트 소유자가 **설정** 에서 만듭니다. 아직 끝나지 않은 선행 이슈가 있는 이슈를 완료로 바꾸면 확인 창이 한 번 더 뜹니다.

## 내가 맡은 일을 모아 본다

사이드바의 **내 작업** 은 모든 프로젝트에서 내 이슈를 모아 보여 줍니다.

![내 작업](shots/user/work-7.png){crop=tabs+filters+group+row marks=tabs,filters,group,row!inside}

1. **할당**(내가 담당자인 이슈)·**내가 만든**·**구독** 탭을 고릅니다.
2. **상태 범주**·**우선순위** 로 거르고, **완료 모두 보기** 로 끝난 이슈도 봅니다.
3. 이슈는 프로젝트별로 묶입니다. 묶음 머리에 프로젝트 이름과 이슈 수가 보입니다.
4. 행을 누르면 이슈가 열립니다. 마감이 지난 이슈는 마감일이 빨간색입니다.

## 진행을 본다

### 타임라인으로 본다

프로젝트 머리의 **타임라인** 을 누르면 에픽과 이슈를 기간 막대로 봅니다.

![타임라인](shots/user/work-8.png){marks=scale,filter,list,milestone}

1. **일**·**주**·**월** 로 눈금을 바꾸고, **오늘** 로 오늘이 있는 곳으로 갑니다. **마일스톤 추가** 로 마일스톤을 만듭니다.
2. 사이클·담당자·**필터** 로 보이는 이슈를 거릅니다.
3. 왼쪽 표에 에픽과 이슈의 시작일·기간이, 오른쪽에 기간 막대가 보입니다. 에픽 이름 옆 괄호는 완료한 하위 이슈 수와 전체 수입니다.
4. 맨 위 **마일스톤** 줄에 마일스톤이, 그 아래 **버전** 줄에 버전이 출시일 자리에 표시됩니다. 표시 아래로 세로 점선이 그어지고, 빨간 세로선은 오늘입니다.

### 사이클과 버전

- **사이클** 화면은 스프린트 같은 기간 단위를 보여 줍니다. 사이클마다 이름, 목표, 기간, 완료한 이슈 수와 비율이 보입니다. **새 사이클** 로 만들고, 연필·휴지통 단추로 고치거나 지웁니다.
- **버전** 화면은 출시 단위로 이슈를 모읍니다. **버전 만들기** 로 버전을 만들면 이슈에 수정 버전·영향 버전 칸이 생기고, 버전을 누르면 그 버전에 묶인 이슈와 진행이 보입니다.

![버전 상세 — 베타 1.0](shots/user/work-9.png){crop=head+actions+issues marks=head,actions@l,tabs,issues}

1. 맨 위에 버전 이름과 상태(**미출시** 등), 기간과 남은 날, 설명, 진행률이 보입니다.
2. **편집** 으로 이름·기간·설명을 고치고, **출시** 로 이 버전을 출시 처리합니다.
3. **이 버전에 나가는 것** 은 수정 버전이 이 버전인 이슈, **이 버전에서 난 결함** 은 영향 버전이 이 버전인 이슈입니다.
4. 이슈가 유형별로 묶여 보입니다. 이슈를 누르면 이슈 상세가 열립니다.

## 프로젝트를 설정한다

프로젝트 머리의 **설정** 은 프로젝트 관리자가 씁니다.

| 항목 | 하는 일 |
| --- | --- |
| **기본 정보** | 프로젝트 이름과 설명을 바꿉니다 |
| **연결된 저장소** | AI 가 이 프로젝트의 이슈를 처리할 때 쓰는 코드 저장소 주소와 기본 브랜치를 정합니다. 개발 프로젝트가 아니면 비워 둡니다 |
| **AI 메모리** | 이 프로젝트에서 일하는 AI 가 함께 읽는 팀 규칙을 관리합니다 |
| **멤버** | 프로젝트에 참여하는 사람·조직과 AI 를 역할과 함께 추가합니다 |

그 아래에서 상태·유형·라벨·컴포넌트·사용자 정의 필드를 관리하고, 맨 아래 **위험 구역** 에서 프로젝트를 삭제합니다.

프로젝트 멤버의 역할은 **소유자** 와 **멤버** 둘입니다.

| 할 수 있는 일 | 소유자 | 멤버 |
| --- | --- | --- |
| 이슈 만들기·고치기, 라벨 만들기 | 예 | 예 |
| 이름·설명 바꾸기, 멤버 추가·제거, 프로젝트 삭제 | 예 | 아니오 |
| 이슈 유형·필드 만들기·고치기·지우기 | 예 | 아니오 |
| 라벨 고치기·지우기 | 예 | 만든 라벨만 |

워크스페이스 관리자는 팀 프로젝트에서 소유자와 같은 일을 할 수 있지만, 다른 사람의 개인 프로젝트는 열 수 없습니다. 소유자는 늘 한 명 이상 있어야 해서 마지막 소유자는 빼거나 역할을 바꿀 수 없습니다. 멤버를 빼면 그 사람이 맡던 이 프로젝트 이슈의 담당자 자리도 함께 비워집니다.

**위험 구역** 의 **프로젝트 삭제** 를 누르면 확인 창이 뜹니다. 삭제하면 이슈와 코멘트도 함께 숨겨지고, 화면에서 되돌릴 수 없습니다. 처음부터 있던 기본 개인 프로젝트 「개인 작업」 은 지울 수 없습니다.

## AI 와 함께 — 이슈를 분류받고 진행 상황을 요약받는다

이슈를 AI 에게 맡기는 방법은 4장에서 다룹니다. 그 밖에 작업 관리에서 AI 를 쓰는 곳은 아래와 같습니다.

| 기능 | 하는 일 | AI 가 하는 방식 |
| --- | --- | --- |
| 새 이슈 창의 **AI 제안 받기** | 제목·본문을 읽고 유형·우선순위·라벨을 제안해 창의 칸을 채웁니다 | 칸만 채웁니다. **생성** 을 눌러야 이슈가 만들어집니다 |
| 이슈 상세의 **AI 제안 받기** | 같은 제안을 지금 이슈에 적용합니다 | 직접 실행합니다. 누르면 우선순위·유형·라벨이 바로 바뀝니다 |
| 이슈 상세의 **AI 현황 요약** | **요약 생성** 을 누르면 이슈의 지금 상황을 요약합니다 | 읽기만 합니다 |
| **AI 어시스턴트** 에 이슈 일 요청 | 이슈 조회·생성·상태 변경·코멘트를 합니다 | 이슈 만들기·바꾸기·코멘트는 직접 실행하고, 이슈·코멘트 삭제는 확인 카드를 띄웁니다 |
| **AI 어시스턴트** 에 프로젝트 일 요청 | 프로젝트 정보·라벨·마일스톤·사이클을 만들거나 고칩니다 | 직접 실행합니다. 프로젝트 만들기·삭제와 멤버 추가·역할 변경·제거는 확인 카드를 띄웁니다 |

### 이슈의 지금 상황을 요약받는다

![AI 현황 요약 — 요약을 만든 뒤](shots/user/work-10.png){crop=card marks=card,generate}

1. 이슈 상세 본문 위 **AI 현황 요약** 에 이슈의 지금 상황과 **다음 액션** 이 나옵니다. 막힌 일이나 마감이 지난 일이 있으면 맨 위에 표시가 붙습니다.
2. 처음에는 **요약 생성**, 요약이 있으면 **요약 갱신** 을 눌러 다시 만듭니다. 옆에 만든 시각이 보입니다.

### 새 이슈 창에서 분류를 제안받는다

![새 이슈 창 — AI 제안 받기로 유형과 우선순위를 채운 모습](shots/user/work-11.png){crop=dialog marks=ai,fields,submit@tr}

1. 제목과 본문을 넣고 **AI 제안 받기** 를 누릅니다. 아래에 그렇게 제안한 이유가 한 줄로 나옵니다.
2. 제안이 **유형**·**우선순위** 칸을 채웁니다. 마음에 들지 않으면 직접 고칩니다.
3. **생성** 을 눌러야 이슈가 만들어집니다.
