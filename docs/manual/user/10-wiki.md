# 노트

노트는 요구사항·회의록·체크리스트처럼 오래 남길 글을 쓰는 곳입니다. 페이지는 스페이스 안에 나무 모양으로 놓이고, 여러 사람이 같은 페이지를 동시에 고칩니다. 쓰는 내용은 자동으로 저장되고, 예전 판으로 되돌릴 수도 있습니다.

> **이 장에서 할 수 있는 일**
>
> - 스페이스와 페이지 목록에서 페이지를 찾아 엽니다.
> - 페이지를 만들고, 동료와 함께 고칩니다.
> - 페이지 메뉴로 보기를 바꾸고 예전 판을 봅니다.
> - 링크로 페이지를 공유합니다.

## 노트 화면을 둘러본다

레일의 **노트** 를 누르고 페이지를 고르면 가운데에 본문이 열립니다. 아래는 팀 스페이스 「모바일 주문 앱」 의 「제품 요구사항 (PRD)」 를 연 모습입니다.

![노트 — 페이지를 연 모습](shots/user/wiki-1.png){marks=space!inside,tree@r,path,header,body!inside}

1. 맨 위 칸에서 스페이스를 고릅니다. 나만 쓰는 「내 노트」 와 팀 스페이스가 있고, 목록 맨 아래 **새 스페이스** 로 팀 스페이스를 만듭니다.
2. **페이지** 아래에 이 스페이스의 페이지가 나무 모양으로 놓입니다. 「+」 로 새 페이지를 만들고, 페이지를 끌어 순서와 위치를 바꿉니다.
3. 위쪽 경로에서 스페이스 이름이나 상위 페이지를 눌러 이동합니다.
4. **공유** 로 링크를 만들고(아래 「링크로 페이지를 공유한다」), 그 옆 **링크 복사** 로 이 페이지의 링크를 복사해 구성원에게 전합니다(2장). 「AI」 로 AI 에게 글쓰기를 맡깁니다. 그 오른쪽 점 세 개 단추는 페이지 메뉴입니다.
5. 본문을 바로 고칩니다. 고친 내용은 자동으로 저장됩니다.

**공유** 왼쪽의 동기화 상태가 **실시간** 이면 입력이 바로 저장되고 있습니다. **오프라인**·**미전송** 이 보이면 연결이 끊긴 동안 쓴 내용이 아직 서버에 가지 않은 것입니다. 연결이 돌아오면 자동으로 보냅니다.

> **참고**
>
> 같은 페이지를 연 동료가 있으면 동료의 커서와 이름이 본문에 함께 보입니다. 서로 다른 곳을 고쳐도 내용이 합쳐집니다.

## 페이지를 만들고 쓴다

**페이지** 옆 「+」 를 누르면 새 페이지가 만들어지고 바로 열립니다. 페이지를 고르지 않았을 때 보이는 **새 페이지 만들기** 를 눌러도 됩니다.

- 맨 위 줄에 제목을 씁니다.
- 본문에서 「/」 를 입력하면 제목·목록·표·이미지 같은 블록을 고르는 메뉴가 열립니다.
- 「@」 를 입력하고 이름을 이어 쓰면 동료를 멘션합니다.
- 이미지는 붙여넣거나 끌어다 놓습니다.

![「/」 를 입력해 연 블록 메뉴](shots/user/wiki-4.png){crop=slash marks=slash@r}

1. 메뉴에서 넣을 블록을 고르거나, 「/」 뒤에 이어 써서 찾습니다. Esc 를 누르면 메뉴가 닫힙니다.

### 글을 상자로 감싼다

안내문이나 요약처럼 눈에 띄게 둘 글은 **상자** 에 넣으면 테두리와 둥근 모서리가 있는 카드처럼 보입니다. 상자 안 글은 다른 글처럼 바로 고칩니다.

1. 「/」 메뉴에서 **상자** 를 고릅니다. 빈 상자가 들어가고 커서가 상자 안에 놓입니다.
2. 상자 안에 글을 씁니다. Enter 로 줄을 늘리고, 목록·표 같은 블록도 넣을 수 있습니다.
3. 다 쓰면 맨 끝 빈 줄에서 Enter 를 누릅니다. 빈 줄이 빠지고 상자 아래 줄로 나갑니다. 마지막 줄 끝에서 ↓ 를 눌러도 됩니다.

이미 쓴 글을 상자에 넣으려면 글을 고른 뒤 위에 뜨는 막대에서 **상자로 감싸기** 를 누릅니다. 고른 글이 걸친 줄들이 상자 하나로 감싸집니다.

상자의 테두리나 위쪽 여백을 누르면 상자 전체가 선택되어 진한 테두리가 보이고, 상자 위에 막대가 나타납니다. 상자 안 글을 누르면 평소처럼 그 자리에서 고칩니다.

- **꾸미기**: 상자 아래에 **상자 꾸미기** 창을 열어 색과 모양을 바꿉니다(아래 「상자를 꾸민다」).
- **↑ 줄 추가**·**↓ 줄 추가**: 상자 바로 위나 아래(상자 밖)에 빈 줄을 만들고 커서를 옮깁니다.
- **글만 남기기**: 상자 모양을 걷어 내고 안의 글은 보통 글로 남깁니다.
- **삭제**: 상자를 안의 글과 함께 지웁니다.

상자가 선택된 채 Enter 나 ↓ 를 누르면 상자 아래 줄로, ↑ 를 누르면 상자 위 줄로 갑니다. 상자 아래에 줄이 없으면 새로 생깁니다. Esc 는 한 단계 바깥으로 나갑니다 — 상자 안에서 쓰다가 누르면 상자 전체가 선택되고, 한 번 더 누르면 상자 옆 줄로 나갑니다. 선택된 상자는 Backspace 나 Delete 로 지웁니다.

> **참고**
>
> 편집 중에는 상자 경계가 옅은 점선으로 보입니다. 공유 링크와 버전 기록에서는 점선 없이 카드 모양만 보입니다. HTML 파일을 가져올 때 들어온 카드도 상자라서 같은 막대와 키로 다룹니다.

### 상자를 꾸민다

상자 막대에서 **꾸미기** 를 누르면 막대 아래에 **상자 꾸미기** 창이 열립니다. 무엇을 누르든 상자 모양이 바로 바뀌고, 같은 노트를 연 사람에게도 바로 보입니다. 바꾼 모양은 공유 링크와 버전 기록에도 같게 보입니다.

- 맨 위 네 칸은 미리 만든 모양입니다. **기본** 은 옅은 테두리, **안내** 는 옅은 파란 바탕에 파란 글자, **주의** 는 옅은 노란 바탕에 주황 테두리, **강조** 는 짙은 남색 바탕에 흰 글자입니다.
- **배경**·**글자색** 은 색 견본을 눌러 고릅니다. **없음**·**기본** 을 누르면 색을 뺍니다.
- **테두리**(**없음**·**얇게**·**굵게**), **모서리**(**각지게**·**둥글게**), **여백**(**좁게**·**보통**·**넓게**), **그림자**(**없음**·**있음**)는 지금 값이 눌린 상태로 보입니다. 다른 값을 누르면 바뀝니다.

한 번 바꾼 것은 ⌘Z(Windows 는 Ctrl+Z) 한 번에 하나씩 되돌아갑니다. Esc 를 누르면 창만 닫히고 상자는 선택된 채로 남습니다. 어두운 테마에서는 같은 모양이 어두운 색으로 바뀌어 보입니다.

CSS 를 아는 사람은 **CSS 로 직접 고치기 →** 를 눌러 그 상자의 모양을 글로 고칩니다.

1. **CSS 로 직접 고치기 →** 를 누릅니다. 지금 모양이 한 줄에 하나씩 채워진 칸이 열립니다.
2. 칸의 글을 고칩니다.
3. **적용** 을 누릅니다. 바꾸지 않고 돌아가려면 **취소** 를 누르거나 Esc 를 누릅니다.

> **참고**
>
> 스크립트를 부르는 값이나 잘못 적은 값처럼 쓸 수 없는 값은 적용할 때 빠집니다. 빠진 것이 있으면 「쓸 수 없는 값 n개를 뺐습니다」 안내와 함께 남은 줄만 칸에 보입니다.

### 차트 같은 HTML 을 넣는다

스크립트로 그리는 차트나 AI 가 만든 HTML 화면은 **HTML 블록** 에 넣으면 노트 안에서 원본처럼 보입니다.

1. 「/」 메뉴에서 **HTML 블록** 을 고릅니다. 소스를 쓰는 칸이 열립니다.
2. HTML 을 붙여 넣거나 씁니다. 왼쪽에 코드가 줄 번호와 함께 색으로 구분되어 보이고, 오른쪽 미리보기가 잠시 뒤 바뀝니다. 화면이 좁으면 미리보기가 코드 아래에 놓입니다.
3. 다 쓰면 블록 위 **완료** 를 누르거나 Esc 를 누릅니다. 소스 칸이 닫히고 블록 전체가 선택됩니다.

평소에는 블록에 미리보기만 보입니다. 마우스를 올리면 블록 위에 막대가 나타납니다. 막대의 **소스 편집** 을 누르면 소스 칸이 다시 열리고, ⋯ 를 누르면 아래 기능을 고를 수 있습니다.

- **다시 올리기**: 고친 HTML 파일(5MB 이하)을 끌어다 놓거나 고르고, 또는 소스를 붙여 넣은 뒤 **바꾸기** 를 누르면 이 블록의 소스만 바뀝니다. 이전 소스는 버전 기록에서 되돌릴 수 있습니다.
- **크게 보기**: 블록을 큰 창으로 띄워 봅니다.
- **삭제**: 블록을 지웁니다.

막대의 **HTML 블록** 이름이나 소스 칸이 닫힌 블록을 누르면 블록 전체가 선택되고 테두리가 보입니다. 선택된 블록은 막대에 다시 올리기·크게 보기·삭제가 바로 보이고, 블록 아래에 키 안내가 나옵니다. 이때 Enter 나 ↓ 를 누르면 블록 아래 줄로, ↑ 를 누르면 블록 위 줄로 갑니다. Esc 는 블록 바깥 옆 줄로, ⌘Enter(Windows 는 Ctrl+Enter)는 바로 아래 줄로 나갑니다. 블록이 노트 맨 끝에 있으면 아래 줄이 새로 생기고, 블록 아래 빈자리를 눌러도 새 줄에서 바로 쓸 수 있습니다. 선택된 블록은 Backspace 나 Delete 로도 지웁니다.

소스 칸 안에서 Enter 는 코드 줄바꿈입니다. 소스를 쓰다가 바로 나가려면 ⌘Enter(Windows 는 Ctrl+Enter)를 누릅니다.

블록 안의 특정 부분을 짚어 두려면 블록 위 막대의 **고르기** 를 누릅니다. 단추가 **고르기 켜짐** 으로 바뀝니다. 블록 안에서 Ctrl(맥은 ⌘)을 누른 채 눌러도 켜집니다.

1. 마우스를 올리면 고를 수 있는 부분에 점선과 이름(제목·카드·차트·표·버튼 등)이 보입니다.
2. 누르면 그 부분에 번호가 붙고, 블록 아래에 번호와 짧은 설명이 칩으로 보입니다. Shift 를 누른 채 누르면 여러 개를 고릅니다.
3. 칩을 누르면 그 부분이 다시 강조되고, 칩 끝의 X 를 누르면 뺍니다.
4. Esc 를 한 번 누르면 고른 것이 풀리고, 한 번 더 누르면 고르기가 꺼지고 블록 전체가 선택됩니다.

고르기가 켜져 있는 동안에는 블록 안 링크나 단추를 눌러도 움직이지 않습니다. 스크립트가 캔버스에 그린 차트는 차트 전체를 한 번에 고릅니다.

> **참고**
>
> HTML 블록은 노트와 떨어진 칸에서 돌아갑니다. 블록 안 스크립트는 노트 화면이나 로그인 정보에 닿지 못합니다. 바깥 인터넷 주소의 스크립트(차트 라이브러리 등)는 불러올 수 있습니다. 공유 링크와 버전 기록에서도 같은 모양으로 보입니다.
>
> AI 어시스턴트에게 AI 가 만든 HTML 화면을 노트로 만들어 달라고 해도 됩니다. 원본 그대로 HTML 블록에 담거나, 고쳐 쓸 수 있는 노트로 바꿔 줍니다. 노트 검색은 HTML 블록 소스와 태그·스타일이 아니라 노트에 보이는 글자를 찾습니다.

### HTML 블록을 AI 로 고친다

차트의 값이나 색, 제목처럼 블록 안 내용을 말로 고치려면 블록 위 막대의 **AI로 고치기** 를 누릅니다. 블록 아래에 요청을 쓰는 칸이 열립니다.

1. 칸에 고칠 내용을 씁니다. 아래 **값 바꾸기**·**색 바꾸기**·**제목 바꾸기**·**항목 추가**·**꺾은선으로** 를 누르면 요청 첫머리가 채워지고, 뒤를 이어 씁니다.
2. 특정 부분만 고치려면 먼저 **고르기** 로 그 부분을 고릅니다. 고른 칩이 칸 안에 보이고, AI 는 고른 부분만 고치고 나머지는 그대로 둡니다. 고른 것이 없으면 블록 전체가 대상입니다.
3. Enter 를 누르거나 **보내기** 를 누릅니다. 줄을 바꾸려면 Shift+Enter 를 누릅니다. 고치는 동안 **취소** 로 멈출 수 있습니다.
4. 결과가 오면 **지금** 과 **바뀐 뒤** 미리보기가 나란히 보입니다(화면이 좁으면 위아래). **바뀐 코드 보기** 를 누르면 바뀐 줄을 코드로 봅니다.
5. 마음에 들면 **적용** 을 누릅니다. 블록 소스가 바뀌고 같은 노트를 연 동료에게도 바로 보입니다. 요청을 고쳐 다시 받으려면 **다시 요청**, 버리려면 **취소** 를 누릅니다. 블록은 그대로입니다.

칸에서 Esc 를 누르면 칸이 닫히고 블록 전체가 선택됩니다. 쓰던 요청은 남아 있어 다시 열면 이어 쓸 수 있습니다. 적용한 뒤 마음에 들지 않으면 실행 취소(Ctrl+Z, Mac 은 Command+Z) 한 번으로 되돌리거나 **버전 기록** 에서 예전 판으로 되돌립니다.

### HTML 파일을 노트로 가져온다

AI 가 만든 보고서 같은 HTML 파일(.html·.htm)을 노트로 가져오면 원본과 비슷한 모양으로 들어오고, 글자는 바로 고칠 수 있습니다.

- 지금 페이지에 넣으려면 「/」 메뉴에서 **HTML 파일 넣기** 를 고르고 파일을 고릅니다. 커서 자리에 들어갑니다.
- 새 페이지로 만들려면 스페이스 이름 옆 ⋯ 에서 **HTML 파일로 새 노트** 를 고릅니다. 어떤 페이지 아래에 만들려면 그 페이지 ⋯ 에서 **HTML 파일로 하위 노트** 를 고릅니다. 파일의 제목이 페이지 제목이 됩니다.
- HTML 파일 소스 전체(`<!doctype html` 로 시작하는 글)를 본문에 붙여 넣어도 같은 방법으로 들어옵니다.

제목·문단·목록·표·링크·이미지는 보통 노트 블록이 되고, 카드나 배지 같은 모양은 그대로 남습니다. 스크립트로 그리는 차트 부분은 HTML 블록이 됩니다. Tailwind CDN 처럼 스크립트로 모양을 입히는 문서는 문서 전체가 HTML 블록 하나로 들어옵니다.

카드 같은 모양은 상자로 들어옵니다(위 「글을 상자로 감싼다」). 카드 안에서 쓰다가 밖으로 나오려면 맨 끝 빈 줄에서 Enter 를 누릅니다. 마지막 줄 끝에서 ↓ 를 눌러도 됩니다. 카드가 노트 맨 끝에 있으면 그 아래에 새 줄이 생깁니다.

가져온 파일에 문서 전체 모양을 정하는 CSS 가 있으면 노트 맨 위에 **페이지 스타일** 칩이 생깁니다. 칩의 **페이지 스타일** 글자를 누르면 그 CSS 를 고치는 창이 열립니다. 상자의 「CSS 로 직접 고치기」와 같은 칸이며, **적용** 하면 쓸 수 없는 값은 빠지고, 빠진 것이 있으면 「쓸 수 없는 값을 뺐습니다」 안내가 보입니다. 칩 오른쪽 끝의 X 단추(**페이지 스타일 지우기**)를 누르면 페이지 스타일을 지웁니다.

> **참고**
>
> 파일 안에 넣어 둔 이미지와 파일 옆 폴더의 이미지는 가져오지 못합니다. 이미지는 따로 올려 주세요. 바깥 글꼴(Google Fonts 등)도 불러오지 않아 기본 글꼴로 보입니다.

### HTML 문서로 그대로 둔다

AI 가 만든 대시보드처럼 원본 그대로 보여야 하는 HTML 은 **HTML 문서** 페이지로 만듭니다. 블록으로 바꾸지 않고 파일 원본을 그대로 보관해 화면 가득 보여 줍니다. 스크립트와 차트도 그대로 돕니다.

1. **페이지** 옆 「+」 오른쪽의 ▾ 를 누릅니다.
2. **HTML 문서** 아래에서 만들 방법을 고릅니다.
   - **파일 올리기**: HTML 파일(.html·.htm)을 고릅니다. 파일 안 제목(없으면 파일 이름)이 페이지 제목이 됩니다.
   - **소스 붙여 넣기**: 창에 HTML 소스를 붙여 넣고 **만들기** 를 누릅니다. 제목을 비우면 소스 안 제목을 씁니다.
   - **빈 문서**: 빈 HTML 문서를 만듭니다. 소스는 나중에 넣습니다.
3. 새 페이지가 바로 열립니다. 트리에서는 제목 옆에 「HTML」 표시가 붙습니다.

▾ 에서 **노트** 를 고르면 「+」 를 누를 때와 같이 빈 노트가 만들어집니다.

HTML 문서 페이지 위쪽 단추로 할 수 있는 일은 이렇습니다.

- **보기** · **소스**: **보기** 는 문서를 그대로 보여 주고, **소스** 는 원본 HTML 을 읽기 전용으로 보여 줍니다.
- **편집**: 왼쪽에 소스 칸, 오른쪽에 미리보기가 열립니다. 고친 뒤 **저장** 을 누르면 반영되고, **취소** 를 누르면 고친 내용을 버립니다. 그사이 다른 사람이 먼저 저장했으면 알림이 뜹니다. 고친 소스는 그대로 남고, 한 번 더 **저장** 을 누르면 지금 소스로 바뀝니다. 먼저 저장된 내용은 **버전 기록** 에 남아 되돌릴 수 있습니다.
- **다시 올리기**: 새 HTML 파일로 원본을 통째로 바꿉니다.
- **원본 내려받기**: 지금 원본을 .html 파일로 내려받습니다.
- **공유**: 노트처럼 링크로 공유합니다([링크로 페이지를 공유한다](#링크로-페이지를-공유한다)). 공유 링크로 연 사람은 보기와 원본 내려받기만 할 수 있습니다.
- **버전 기록**: 저장하거나 다시 올릴 때마다 이전 원본이 남습니다. 판을 고르면 그 원본을 미리 보고, **이 버전으로 되돌리기** 로 되돌립니다.

화면이 좁으면 **다시 올리기** · **원본 내려받기** · **버전 기록** 은 아이콘으로만 보입니다. 아이콘에 마우스를 올리면 이름이 나옵니다.

제목은 단추 아래 제목 줄에서 바로 고칩니다. 보기 전용 멤버는 **편집** 과 **다시 올리기** 가 보이지 않습니다.

HTML 문서는 한 번에 한 사람만 고칩니다. **편집** 을 누르면 그 사람이 문서를 잡고, **저장** 이나 **취소** 를 누르면 놓습니다.

- 다른 사람이 편집하는 동안에는 위에 「○○ 님이 편집 중입니다 — 저장될 때까지 보기만 할 수 있어요」 띠가 뜹니다. 그동안 **편집** 과 **다시 올리기**, 버전 기록의 **이 버전으로 되돌리기** 는 누를 수 없습니다. 보기·소스·원본 내려받기는 그대로 됩니다.
- 같은 문서를 다른 창에서 다시 **편집** 하면 새 창이 이어받고, 먼저 연 창의 편집은 끝납니다. 고치던 내용은 임시 저장본으로 남습니다.
- 입력 없이 10분이 지나면 편집이 저절로 끝납니다. 창을 닫거나 연결이 끊겨도 같습니다. 고치던 내용은 그 사람의 임시 저장본으로 남습니다.
- 임시 저장본이 남은 문서에서 **편집** 을 누르면 **이어 고치기** 와 **새로 시작** 중에서 고릅니다. 그사이 다른 사람이 저장했으면 그 사실도 함께 알려 줍니다.
- 스페이스 소유자는 띠의 **잠금 풀기** 로 다른 사람의 편집을 끝낼 수 있습니다. 그 사람이 고치던 내용은 임시 저장본으로 남습니다.
- AI 비서와 MCP 로 원본을 바꿀 때도 같습니다. 누가 편집하는 동안에는 바꾸지 못하고, 편집 중이라는 이유를 알려 줍니다.

> **참고**
>
> HTML 문서는 5MB 까지 올릴 수 있습니다. 문서는 노트와 떨어진 칸에서 돌아가므로, 스크립트는 노트 화면이나 로그인 정보에 닿지 못합니다.
>
> 위의 **HTML 파일로 새 노트** 는 파일을 노트 블록으로 바꿔 넣어 글자를 바로 고칠 수 있게 합니다. HTML 문서는 바꾸지 않고 원본 그대로 두므로, 고칠 때는 소스를 고칩니다. 원본 모양을 그대로 지켜야 하면 HTML 문서를, 노트처럼 함께 고쳐 쓰려면 **HTML 파일로 새 노트** 를 고르세요.

## 페이지 메뉴를 쓴다

![페이지 메뉴](shots/user/wiki-2.png){crop=trigger+menu marks=trigger,menu@bl,history@l}

1. 오른쪽 위 점 세 개 단추(**페이지 메뉴**)를 누릅니다.
2. **전체 폭** 을 켜면 본문이 화면 폭을 다 씁니다. **마크다운 소스** 는 본문을 마크다운으로 보여 줍니다.
3. **버전 기록** 을 누르면 이 페이지의 예전 판이 시간순으로 나옵니다. 예전 판을 골라 지금과 비교하고, 그 판으로 되돌립니다.

같은 메뉴의 **페이지 삭제** 로 페이지를 지웁니다.

> **경고**
>
> 페이지를 지우면 그 아래 하위 페이지도 함께 지워집니다. 노트에는 휴지통이 없어 지운 페이지는 되살릴 수 없습니다. **버전 기록** 으로 되돌릴 수 있는 것은 아직 남아 있는 페이지의 예전 판뿐입니다.

## 링크로 페이지를 공유한다

오른쪽 위 **공유** 를 누르면 **페이지 공유** 창이 열립니다. 휴대폰에서는 위쪽 **공유** 단추의 **외부 공유 링크…** 로 엽니다. 처음에는 스페이스 멤버만 이 페이지를 볼 수 있습니다. 아래 그림은 이미 링크로 공유한 「제품 요구사항 (PRD)」 의 창입니다.

![페이지 공유 창](shots/user/wiki-3.png){crop=dialog marks=toggle@l,link,fields}

1. **링크로 공유** 를 켭니다. 링크가 만들어집니다.
2. **링크 복사** 로 링크를 복사해 전합니다. 그 아래에 링크가 마지막으로 열린 시각과 열린 횟수가 보입니다.
3. 누가 어떤 권한으로 언제까지 열 수 있는지 정합니다(아래 표).

| 칸 | 고를 수 있는 값 |
| --- | --- |
| **열 수 있는 사람** | **워크스페이스 멤버 누구나**·**지정한 사람만**, 관리자가 허용했으면 링크가 있는 누구나(외부) |
| **권한** | **보기만**·**편집 가능** |
| **만료** | 링크를 쓸 수 있는 마지막 날 |

링크를 받은 사람은 스페이스 멤버가 아니어도 그 페이지를 봅니다. **하위 페이지도 함께 공유** 를 켜면 하위 페이지도 함께 보입니다. 이 스페이스에서 공유 중인 페이지는 스페이스 메뉴의 **공유 중인 페이지** 에서 모아 봅니다.

> **주의**
>
> 외부 링크는 주소를 아는 사람 누구나 로그인 없이 봅니다. 필요한 기간만큼만 만료일을 두고 씁니다.

## 스페이스를 관리한다

스페이스 칸 옆 점 세 개 단추를 누르면 **멤버**·**공유 중인 페이지**·**스페이스 삭제** 가 나옵니다. **멤버** 와 **스페이스 삭제** 는 팀 스페이스에만 있고, **스페이스 삭제** 는 소유자만 합니다.

| 역할 | 할 수 있는 일 |
| --- | --- |
| **소유자** | 편집자가 하는 일에 더해 멤버 관리, 스페이스 삭제 |
| **편집자** | 페이지 만들기·고치기·옮기기·지우기, 페이지 링크 공유 |
| **보기 전용** | 페이지 읽기 |

부서를 멤버로 넣으면 **편집자** 나 **보기 전용** 만 고를 수 있습니다.

## AI 와 함께 — 초안을 받고 페이지 정리를 맡긴다

| 기능 | 하는 일 | AI 가 하는 방식 |
| --- | --- | --- |
| **AI 초안으로 시작** | 새 페이지를 AI 가 쓴 초안으로 시작합니다 | 초안을 페이지에 직접 씁니다 |
| 페이지 머리의 「AI」 | 지금 페이지에 글을 써 넣거나 고칩니다(**AI 작성**) | 본문을 직접 고칩니다. 고친 내용은 **버전 기록** 에 남아 되돌릴 수 있습니다 |
| HTML 블록의 **AI로 고치기** | 블록 안 HTML 을 요청대로 고칩니다 | 고친 결과를 먼저 보여 주고, **적용** 을 눌러야 블록이 바뀝니다 |
| **AI 어시스턴트** 에 노트 일 요청 | 페이지 검색·읽기, 새 페이지 만들기, 페이지 고치기·옮기기, 예전 판으로 되돌리기 | 직접 실행합니다. 페이지 삭제는 확인 카드를 띄웁니다 |

**AI 초안으로 시작** 은 **AI 초안 작성** 창에서 주제만 묻고, **AI 작성** 은 요청을 받은 뒤 바로 씁니다. 두 기능 모두 미리 보기나 확인 단계 없이 결과가 커서 자리(없으면 페이지 끝)에 들어가고, 같은 페이지를 연 동료에게도 바로 보입니다. 마음에 들지 않으면 실행 취소(Ctrl+Z, Mac 은 Command+Z) 한 번으로 통째로 되돌리거나 **버전 기록** 에서 예전 판으로 되돌립니다.
