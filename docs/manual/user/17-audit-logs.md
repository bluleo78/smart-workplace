# 감사 로그

감사 로그는 워크스페이스에서 누가 언제 무엇을 했는지 남는 기록입니다. 로그인, 구성원 계정 생성, 토큰 발급, 파일 업로드, 에이전트 설정 같은 일이 한 줄씩 쌓입니다. 관리자는 **워크스페이스 관리** 의 **감사 로그** 에서 기록을 찾아봅니다.

> **이 장에서 할 수 있는 일**
>
> - 설명·사용자·결과·기간으로 기록을 찾습니다.
> - 액션 유형·리소스로 거릅니다.
> - 기록 한 줄의 상세를 봅니다.

## 기록을 찾는다

![감사 로그 필터 — 폭이 좁은 창에서 날짜 칸이 둘째 줄로 내려간 모습](shots/user/audit-logs-1.png){crop=area+dates marks=search@l,user!inside,result!inside,dates}

1. **설명으로 검색...** 칸에 설명 일부를 넣습니다. 아래 그림들은 「구성원 계정 생성」 으로 찾은 모습입니다.
2. **전체 사용자** 에서 한 사람을 고르면 그 사람의 기록만 보입니다.
3. **전체 결과** 에서 **성공**·**실패** 를 고릅니다.
4. 두 날짜 칸으로 기간을 정합니다.
5. 사용자 칸 오른쪽 **필터** 로 액션 유형이나 리소스를 고릅니다(아래 「액션 유형과 리소스로 거른다」).

찾은 기록 수는 필터 줄 끝에 총 n건으로 보입니다.

### 기록을 읽는다

![감사 로그 표 — 시간부터 설명까지](shots/user/audit-logs-3.png){crop=area marks=rows!inside}

1. 행마다 시간·사용자·액션·리소스·설명이 보입니다.

표 오른쪽에는 결과(성공·실패)와 요청이 온 IP 열이 더 있습니다.

행을 누르면 **감사 로그 상세** 창에 시간·사용자·액션·리소스·결과·IP 주소·설명이 보이고, 기록에 따라 에러 메시지, 사용한 브라우저 정보, 바뀐 값 같은 추가 정보가 함께 보입니다.

## 액션 유형과 리소스로 거른다

![필터 메뉴](shots/user/audit-logs-2.png){crop=trigger+menu marks=trigger,menu}

1. **필터** 를 누릅니다.
2. **액션 유형**(로그인 등) 또는 **리소스**(인증·사용자 등)를 고르고 값을 고릅니다. 고른 조건은 칩으로 보이고, 칩마다 한 값만 고를 수 있습니다.

화면에서 감사 로그를 지우거나 파일로 내보내는 기능은 없습니다. 기록을 얼마 동안 보관하는지는 서비스 운영자에게 문의합니다.

AI 에이전트가 한 일도 기록됩니다. 에이전트는 구성원 계정이라 사용자 열에 에이전트의 아이디(예: genie)가 보입니다.
