# 문제 해결

자주 겪는 문제와 확인할 곳을 모았습니다. 증상을 찾아 위에서부터 차례로 확인합니다.

## 로그인이 안 된다

| 화면에 보이는 것 | 확인할 것 |
| --- | --- |
| **아이디 또는 비밀번호가 올바르지 않습니다.** | 아이디는 회사 계정 주소(이메일) 전체입니다. 비밀번호의 대소문자를 확인합니다. 비밀번호를 스스로 다시 정하는 화면은 없으므로, 잊었으면 관리자에게 문의합니다 |
| **로그인 시도 횟수를 초과하였습니다. 잠시 후 다시 시도해 주세요.** | 비밀번호를 5번 연달아 틀려 계정이 잠겼습니다. 마지막으로 틀린 때부터 15분이 지나면 다시 로그인할 수 있습니다 |
| Microsoft 로그인에서 "관리자 승인 필요" | 회사 Entra 관리자가 아직 동의하지 않았습니다. 워크스페이스 관리자가 **관리자 동의 링크** 를 회사 Entra 관리자에게 전달해 승인받습니다(16장) |
| Microsoft 로그인은 되지만 워크스페이스에 들어가지 못한다 | 그 Microsoft 주소로 등록된 구성원이 없거나, 아이디가 Microsoft 로그인 주소와 다릅니다. 관리자에게 구성원 등록을 요청합니다(14장) |
| **접속 가능한 워크스페이스가 없습니다. 관리자에게 문의하세요.** | 들어갈 수 있는 워크스페이스가 없습니다. 관리자가 나를 비활성화했을 수 있습니다(14장). 다른 워크스페이스에도 속해 있으면 이 문구 대신 그 워크스페이스만 보입니다 |

## 알림이 오지 않는다

1. **설정** → **알림** 에서 그 알림 종류가 켜져 있는지 확인합니다. 사람이 한 일과 AI 가 한 일은 따로 켭니다(12장).
2. 푸시를 받으려면 **이 기기에서 푸시 받기** 가 켜져 있어야 합니다. 이 스위치는 브라우저마다 따로입니다. 같은 컴퓨터라도 다른 브라우저에서는 따로 켭니다.
3. **알림 권한이 차단되어 있습니다** 안내가 보이면 브라우저 주소창의 사이트 설정(또는 OS 설정 > 알림)에서 이 사이트의 알림을 허용합니다.
4. iPhone·iPad 는 홈 화면에 추가한 앱에서만 알림을 받습니다(13장).
5. 로그아웃하면 그 기기로는 푸시가 오지 않습니다. 같은 브라우저로 다시 로그인하면 다시 받습니다.

채팅(DM·채널 멘션)은 알림 목록에 쌓이지 않고 푸시로만 옵니다. 그 대화를 지금 보고 있으면 푸시를 띄우지 않습니다.

## 노트에 「오프라인」·「새 버전」 안내가 보인다

- 노트 위쪽 동기화 상태가 **오프라인** 이면 연결이 끊긴 것입니다. 입력한 내용은 이 화면을 닫지 않는 동안 보관되고, 연결이 돌아오면 자동으로 보냅니다. 연결이 돌아올 때까지 탭을 닫지 않습니다.
- **새 버전이 배포되었어요** 안내가 보이면 **새로고침** 을 누릅니다. 아직 서버로 가지 않은 입력은 저장되지 않으므로, 오프라인이었다면 연결이 돌아온 뒤 누릅니다.

## AI 어시스턴트 단추가 보이지 않는다

화면 위 **AI 어시스턴트** 단추는 나를 맡을 AI 비서가 있을 때만 보입니다. 관리자가 공통 비서를 지정했거나(15장), 내가 개인 비서를 등록했으면(12장) 보입니다. 둘 다 없으면 관리자에게 공통 비서 지정을 요청합니다.

## 외부 AI 도구가 연결되지 않는다

- 토큰을 잃어버렸으면 **설정** → **API 토큰** 에서 그 토큰을 **폐기** 하고 새로 발급합니다. 토큰은 발급할 때 한 번만 보입니다(12장).
- 만료된 토큰은 쓸 수 없습니다. 목록의 만료 날짜를 확인합니다.
- **도구에 연결하기** 의 명령과 연결 주소를 다시 확인합니다.

## 설정에 「워크스페이스 관리」가 보이지 않는다

**워크스페이스 관리** 와 **앱 설정** 은 ADMIN 역할이 있는 구성원에게만 보입니다. 다른 역할에 같은 권한을 줘도 보이지 않습니다(14장).
