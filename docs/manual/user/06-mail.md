# 메일

메일은 내가 연결한 메일 계정(Outlook·IMAP)의 메일을 Gen:iA Works 안에서 읽고 씁니다. 메일 서버와 동기화되므로 여기서 읽음 표시·보관·삭제를 하면 원래 메일 서버에도 반영됩니다. 메일 계정은 **설정** → **메일 계정** 에서 연결합니다(12장).

> **이 장에서 할 수 있는 일**
>
> - 받은편지함과 분류·메일함을 오가며 메일을 찾습니다.
> - 메일을 읽고 답장·전달하고, 보관·옮기기·삭제합니다.
> - 새 메일을 쓰고, 쓰다 만 메일을 임시보관함에서 이어 씁니다.
> - 메일에 온 일정 초대에 응답합니다.
> - AI 로 메일을 요약하고 답장·이슈 초안을 받습니다.

## 메일 화면을 둘러본다

레일의 **메일** 을 누르면 왼쪽에 메일함 목록이, 가운데에 메일 목록이, 오른쪽에 고른 메일이 열립니다. 연결한 메일 계정이 없으면 **연결된 메일 계정이 없습니다** 와 **메일 계정 연결** 단추가 보입니다.

왼쪽 메일함 목록에는 위에서부터 계정 고르기, **편지쓰기**, 메일함이 있습니다.

| 메일함 | 담기는 메일 |
| --- | --- |
| **받은편지함** | 받은 메일 전체. 옆 숫자는 안 읽은 메일 수입니다 |
| **업무**·**개인**·**알림**·**프로모션**·**뉴스레터** | 받은편지함을 AI 가 나눈 분류입니다. **업무** 에는 아직 분류되지 않은 메일도 함께 보입니다 |
| **보낸편지함** | 보낸 메일 |
| **임시보관함** | 쓰다가 닫은 메일. 옆 숫자는 임시저장한 메일 수입니다 |
| **보관** | 보관한 메일(메일 서버에 보관 메일함이 있을 때만 보입니다) |
| **내 메일함** | 메일 서버에 내가 만든 메일함(있을 때만 보입니다) |
| **회신필요** | 안 읽은 메일 중 AI 가 답장이 필요하다고 본 메일(**AI 필터** 아래, 있을 때만 보입니다). 메일을 열면 빠집니다 |

맨 아래 **계정 관리** 를 누르면 **설정** → **메일 계정** 으로 갑니다. 연결한 계정이 둘 이상이면 맨 위 계정 칸에서 계정을 바꿉니다.

분류는 AI 비서가 쓸 수 있을 때만 나옵니다. 아직 분류하지 않은 메일은 목록에 **분류 전** 이 붙습니다.

## 메일을 찾는다

화면 오른쪽 위 **제목·보낸사람 검색** 칸에 찾을 말을 넣으면 지금 메일함에서 제목·보낸 사람·본문에 그 말이 들어간 메일이 목록에 남습니다. 목록 위에는 지금 보는 곳과 동기화 상태가 보입니다.

![경로와 목록 위 도구 줄 — 검색한 모습](shots/user/mail-1.png){crop=area marks=path,sync,unread,markAll@r}

1. 지금 보는 메일함의 경로입니다. 검색하면 끝에 **검색 결과** 가 붙습니다. 앞쪽 이름을 누르면 그 메일함으로 돌아갑니다.
2. 새로고침 단추를 누르면 메일 서버에서 새 메일을 바로 가져옵니다. 옆에 마지막으로 동기화한 시각이 보이고, 가져오는 동안에는 본문을 받은 수가 보입니다.
3. **안 읽은 메일만** 을 켜면 안 읽은 메일만 남습니다.
4. **모두 읽음** 을 누르면 **모두 읽음으로 표시할까요?** 창이 열립니다. **읽음으로 표시** 를 누르면 지금 보는 곳의 안 읽은 메일이 모두 읽음이 되고, 메일 서버에도 반영됩니다.

목록을 끝까지 내리면 그 앞 90일의 이전 메일을 메일 서버에서 더 가져옵니다. 더 가져올 메일이 없으면 **더 이전 메일 없음** 이 보입니다.

## 메일을 읽는다

목록에서 메일을 누르면 오른쪽에 제목·보낸 사람·받는 사람과 본문이 열립니다. 처음 연 메일은 읽음이 됩니다. 목록의 행에 마우스를 올리면 보관·옮기기·삭제·읽음 표시 단추가 행 위에 나타나 메일을 열지 않고도 처리합니다.

![메일 상세 — 단추 줄과 본문](shots/user/mail-2.png){crop=area marks=actions@r,body}

1. 단추 줄에서 메일을 처리합니다.
   - **답장**·**전체답장**·**전달** 을 누르면 작성 창이 열립니다. 받는 사람과 제목이 채워지고, 원문은 **인용된 원문** 으로 붙습니다.
   - **안 읽음** 은 다시 안 읽음으로 돌리고 메일을 닫습니다. **보관** 은 보관 메일함으로, **옮기기** 는 **옮길 메일함** 에서 고른 메일함으로 옮깁니다. **삭제** 는 휴지통으로 보냅니다.
2. 본문이 보입니다. 첨부가 있으면 첨부 목록이 함께 보이고, 첨부를 누르면 미리 보기가 열립니다.

메일로 할 일을 이어 가려면 이슈로 만듭니다(아래 「AI 와 함께」). 이슈로 만든 메일에는 위에 **이슈로 만듦:** 과 이슈 키가 보입니다.

### 일정 초대에 응답한다

일정 초대 메일을 열면 본문 위에 **일정 초대** 카드가 보입니다. 카드에는 일정 제목·일시·장소·주최자·참석자 수가 있고, **수락**·**미정**·**거절** 로 응답합니다. 응답은 주최자에게 전해지고 내 캘린더에도 반영됩니다(7장). **캘린더에서 보기** 를 누르면 그 일정이 캘린더에서 열립니다. 주최자가 일정을 취소하면 **취소된 일정** 카드가 보입니다.

## 메일을 쓴다

왼쪽 **편지쓰기** 를 누르면 화면 오른쪽 아래에 **새 메일** 창이 열립니다. 창을 연 채로 다른 메일을 읽을 수 있습니다.

![새 메일 창](shots/user/mail-3.png){crop=dock marks=to,subject,tabs,send}

1. **받는사람** 에 이름이나 주소를 넣고 후보에서 고릅니다. **참조/숨은참조** 를 누르면 **참조**·**숨은참조** 칸이 나옵니다.
2. **제목** 을 넣습니다.
3. **작성** 에서 본문을 씁니다. 도구 줄로 굵게·기울임·목록·링크를 넣습니다. **AI 검토** 는 아래 「AI 와 함께」 를 봅니다.
4. **보내기** 를 누릅니다. 클립 단추로 파일을 붙이고, 휴지통 단추로 쓰던 메일을 버립니다.

창 머리의 단추로 창을 작게 접거나 크게 키웁니다. 쓰던 내용이 있는 채로 창을 닫으면 메일이 **임시보관함** 에 저장됩니다. **임시보관함** 에서 메일을 고르면 작성 창에서 이어 씁니다.

> **주의**
>
> 보낸 메일은 되돌릴 수 없습니다. 받는 사람과 첨부를 확인한 뒤 **보내기** 를 누릅니다.

## AI 와 함께 — 메일을 요약하고 답장·이슈 초안을 받는다

메일 계정 화면의 **개인 비서 사용** 을 켜면(12장) 메일 상세에 **AI 답장 초안** 과 **AI 이슈 생성** 단추가 나옵니다. AI 비서를 쓸 수 있는 워크스페이스에서는 메일 위에 **AI 요약** 이 함께 보입니다. 짧은 메일은 요약을 건너뛰고, **AI 요약** 단추를 누르면 그때 만듭니다.

| 기능 | 하는 일 | AI 의 권한 |
| --- | --- | --- |
| **AI 요약** | 메일 내용을 몇 줄로 요약해 본문 위에 보여 줍니다 | 읽기만 |
| 분류·**회신필요** | 받은 메일을 업무·개인 등으로 나누고, 답장이 필요한 안 읽은 메일을 가려냅니다 | 읽기만 — 메일을 바꾸지 않습니다 |
| **AI 답장 초안** | 답장 창을 열고 본문에 답장 초안을 넣습니다. 고친 뒤 직접 보냅니다 | 초안만 — 보내지 않습니다 |
| **AI 이슈 생성** | **이슈로 만들기 (AI 초안)** 창에 이슈 제목·본문 초안을 채웁니다. **이슈 생성** 을 눌러야 이슈가 만들어지고 메일과 연결됩니다 | 초안만 — 사람이 만듭니다 |
| **AI 검토** 탭 | 쓰는 중인 메일을 검토해 **전체 코칭** 과 **다듬은 개선본** 을 보여 줍니다. **개선본으로 교체** 를 눌러야 본문이 바뀝니다 | 제안만 |
| **AI로 쓰기** | 작성 창에서 「다음 주 회의를 목요일로 옮기자고 요청」처럼 쓸 내용을 적으면 본문 초안을 씁니다. **되돌리기** 로 원래 본문으로 돌아갑니다 | 초안만 |

화면 위 **AI 어시스턴트** 에게 「안 읽은 메일 정리해 줘」, 「이 메일로 이슈 만들어 줘」처럼 맡길 수도 있습니다. AI 어시스턴트는 메일을 찾아 읽고, 동기화하고, 요청할 때만 읽음·안 읽음을 바꿉니다. 메일로 이슈를 만드는 일은 바로 실행합니다. 메일 보내기는 직접 하지 않고 확인 카드로 제안하며, **승인** 을 눌러야 보내집니다.
