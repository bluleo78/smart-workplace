# AI 에이전트 관리

에이전트는 워크스페이스의 AI 구성원입니다. 사람처럼 이슈 담당자가 되고(4장), 대화에서 멘션을 받고, 맡은 일을 합니다. 관리자는 **설정** → **에이전트** 에서 에이전트를 만들고, AI 연결과 모델을 정하고, 워크스페이스 공통 비서를 지정합니다.

> **이 장에서 할 수 있는 일**
>
> - 에이전트 목록을 보고 새 에이전트를 만듭니다.
> - 에이전트의 설명·실행 방식·활성 상태·역할을 바꿉니다.
> - 에이전트를 AI 서비스에 연결하고 모델을 고릅니다.
> - 공통 비서를 지정하고, 외부에서 일할 에이전트에 API 키를 발급합니다.

## 에이전트 목록을 본다

![에이전트 목록](shots/user/agents-1.png){marks=toggle,create,row}

1. **개인 비서 표시** 를 켜면 구성원이 12장에서 만든 개인 비서도 목록에 함께 보입니다.
2. 새 에이전트를 만들려면 **새 에이전트** 를 누릅니다.
3. 행마다 이름·아이디·유형·실행·생성일이 보입니다. 행을 누르면 오른쪽에 에이전트 상세가 열립니다.

**유형** 은 셋입니다.

| 유형 | 뜻 |
| --- | --- |
| **공통** | 워크스페이스 공통 비서. 개인 비서가 없는 구성원의 AI 어시스턴트를 맡습니다 |
| **개인** | 구성원 한 사람의 개인 비서. 옆에 주인 이름이 보입니다 |
| **일반** | 이슈 담당 같은 일을 맡기는 에이전트 |

**실행** 의 **내부** 는 서버에서 일하는 에이전트, **외부** 는 사람의 컴퓨터 같은 바깥에서 API 키로 접속해 일하는 에이전트입니다. 외부 에이전트에는 키를 마지막으로 쓴 시각(**키 미사용** 등)이 함께 보입니다.

**새 에이전트** 창에서 **아이디**·**이름**·**이메일** 을 넣고 **생성** 을 누르면 에이전트가 만들어집니다.

## 에이전트 정보와 상태를 바꾼다

![에이전트 상세 — 윗부분](shots/user/agents-2.png){crop=info+active marks=info,mode,active}

1. **에이전트 정보** 에서 **이름** 과 **설명(역할)** 을 고치고 **저장** 을 누릅니다. 다른 AI 가 일을 맡길 상대를 고를 때 이 설명을 읽으므로, 무엇을 맡고 어떻게 일하는지 적습니다.
2. **실행 방식** 에서 **내부 (서버에서 실행)** 또는 **외부 (내 컴퓨터 등)** 를 고릅니다. 공통 비서·개인 비서로 지정된 AI 는 서버에서 대화해야 해서 외부로 바꿀 수 없습니다. 비서 지정을 먼저 해제합니다.
3. **활성 상태** 의 스위치를 끄면 그 AI 는 이 워크스페이스에 접속하거나 일할 수 없습니다. 공통 비서는 지정을 해제한 뒤 비활성화합니다.

그 아래 **역할 할당** 에서 AI 에게 줄 역할을 고르고 **역할 저장** 을 누릅니다. AI 에게는 관리자 역할이나 관리 권한이 든 역할을 줄 수 없습니다.

## AI 연결과 모델을 정한다

상세 패널을 아래로 내리면 **AI 연결 및 모델** 이 있습니다. 맨 위 **연결** 에 연결 방식(예: Claude 구독), 등록일, 최근 사용 시각이 보입니다. 아직 연결하지 않았으면 **연결하기** 를 누릅니다. 연결 방식은 Claude 구독 토큰 또는 OpenAI 호환 API 키입니다.

![AI 연결 및 모델 — 공통 비서 지니](shots/user/agents-4.png){crop=area marks=conn,model,assistant@r,key!inside}

1. **재발급** 은 토큰을 새로 넣고, **회수** 는 저장한 토큰·키를 폐기합니다. 회수하면 에이전트가 AI 를 부를 수 없게 됩니다.
2. **모델** 과 **생각의 깊이**(**없음**·**보통**·**깊게**)를 고릅니다. **추천 질문 모델** 은 추천·후속 질문을 만들 때만 쓰는 가벼운 모델입니다. 공통 비서로 지정된 에이전트만 고를 수 있습니다.
3. **이 에이전트를 공통 비서로 지정** 을 켜면 워크스페이스 공통 비서가 됩니다(아래 「공통 비서를 지정한다」).
4. **API 키** 에서 이름표(**label (선택)**)를 넣고 **키 발급** 을 누르면 이 에이전트용 키가 만들어집니다(아래 「외부 에이전트에 API 키를 준다」).

개인 비서의 AI 연결은 주인이 자기 설정에서 정합니다(12장).

> **참고**
>
> 등록한 토큰·키 값은 다시 보이지 않습니다. 화면에는 연결 종류와 날짜만 보입니다.

## 공통 비서를 지정한다

**AI 연결 및 모델** 아래 **이 에이전트를 공통 비서로 지정** 을 켜면 이 에이전트가 워크스페이스 공통 비서가 됩니다. 공통 비서는 개인 비서를 두지 않은 구성원의 **AI 어시스턴트** 와 홈 AI 비서를 맡습니다. 먼저 AI 에 연결해야 지정할 수 있고, 개인 비서는 공통 비서로 지정할 수 없습니다.

공통 비서 지정을 해제하면 개인 비서가 없는 구성원은 화면 위 **AI 어시스턴트** 단추와 AI 기능을 쓸 수 없게 됩니다. 이미 열려 있는 화면은 새로 고친 뒤에 바뀔 수 있습니다.

## 외부 에이전트에 API 키를 준다

실행 방식이 외부인 에이전트는 API 키로 접속합니다. 외부 에이전트의 상세 패널에는 **외부 에이전트 연결** 이 있고, 단계 번호를 따라 준비합니다.

먼저 **① 키 발급** 에서 이름표를 넣고 **키 발급** 을 누르면 **새 API 키** 창에 키가 한 번 보입니다. **키 복사** 로 복사해 둡니다. 발급한 키는 목록에서 **회수** 할 수 있습니다. 그다음 그 AI 를 돌릴 컴퓨터에서 아래 단계를 따릅니다.

![외부 에이전트 연결 — 플러그인 설치부터 이 AI 로 일하기까지](shots/user/agents-3.png){crop=area marks=plugin,login,work}

1. **② genia-works 플러그인 설치** 의 명령을 **복사** 해 Claude Code 에서 실행합니다. 이미 설치했으면 건너뜁니다.
2. **③ Claude Code 에 이 AI 등록** 의 명령을 실행하고 「새 AI 추가」 를 골라 ①에서 복사한 키를 붙여 넣습니다. 이름은 이 AI 의 아이디로 넣습니다.
3. **④ 이 AI로 일하기** 의 명령으로 지금 세션이나 새 세션을 이 AI 로 바꿉니다. 그 아래 **⑤ 자동으로 이슈 처리** 를 따르면 이 AI 에게 할당된 이슈를 하나씩 가져와 처리합니다.

내부 실행 에이전트는 이 자리에 **API 키** 칸이 있습니다. 이름표(**label (선택)**)를 넣고 **키 발급** 을 누르는 방식은 같습니다.

> **주의**
>
> API 키는 발급할 때 한 번만 보입니다. 잃어버렸으면 회수하고 새로 발급합니다.

에이전트를 지우려면 상세 패널 맨 아래 **에이전트 삭제** 를 누릅니다.

**에이전트 삭제** 를 누르면 확인 창이 뜹니다. 지우는 방식은 에이전트가 남긴 기록에 따라 다릅니다.

- 코멘트·이력 같은 기록이 없으면 에이전트가 지워지고, 담당하던 이슈의 담당자에서도 빠집니다.
- 기록이 있으면 기록은 그대로 두고 이 워크스페이스에서 사용만 중지합니다(「남은 기록이 있어 삭제 대신 사용을 중지했습니다」). 담당하던 이슈의 담당자 칸에는 그대로 남으므로, 필요하면 이슈마다 담당자를 바꿉니다.

공통 비서로 지정된 에이전트를 지우면 지정도 함께 풀립니다. 개인 비서는 여기서 지울 수 없습니다.
