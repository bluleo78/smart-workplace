# 테넌트 만들기와 고치기

테넌트는 Gen:iA Works 를 쓰는 회사 하나의 업무 공간입니다. 구성원에게는 워크스페이스로 보입니다. 이 장에서는 테넌트 목록과 상세 화면을 보고, 테넌트를 새로 만들고, 이름·slug·드라이브 용량 한도를 고칩니다.

> **이 장에서 할 수 있는 일**
>
> - 테넌트 목록을 보고 상태를 확인합니다.
> - 새 테넌트를 만들고 소유자를 정합니다.
> - 테넌트의 이름과 slug 를 고칩니다.
> - 테넌트의 드라이브 용량 한도를 바꿉니다.

## 테넌트 목록을 본다

왼쪽 메뉴의 **테넌트** 를 누르면 테넌트 목록이 열립니다. 목록에는 **이름**·**슬러그**·**상태**·**멤버수**·**생성일** 이 보입니다.

![테넌트 목록 — 보기 전환과 테넌트 행](shots/operator/tenants-1.png){crop=header+table marks=toggle,row}

1. 목록 위의 **운영 중**·**삭제됨** 으로 볼 테넌트를 고릅니다. 이름 옆 숫자는 테넌트 수입니다.
2. 테넌트 이름을 누릅니다. 테넌트 상세 화면이 열립니다.

**운영 중** 에는 활성·정지된 테넌트가, **삭제됨** 에는 삭제되었거나 영구 삭제 중인 테넌트가 나옵니다. **삭제됨** 에서는 마지막 열이 **삭제일** 로 바뀝니다.

테넌트의 상태는 네 가지입니다. 상태를 바꾸는 방법은 [4장](04-tenant-lifecycle.md)에서 다룹니다.

| 상태 | 뜻 |
| --- | --- |
| **활성** | 구성원이 들어와 일할 수 있습니다 |
| **정지됨** | 구성원이 들어올 수 없습니다. 데이터는 그대로 있고 다시 활성화할 수 있습니다 |
| **삭제됨** | 구성원이 들어올 수 없고 정보를 고칠 수 없습니다. 영구 삭제하기 전까지 복원할 수 있습니다 |
| **영구 삭제 중…** | 데이터를 지우고 있습니다. 되돌릴 수 없습니다 |

목록 맨 위의 「Default Workspace」 는 서비스를 설치할 때 함께 만들어지는 기본 테넌트입니다. 기본 테넌트는 삭제할 수 없습니다.

## 새 테넌트를 만든다

목록 오른쪽 위의 **테넌트 생성** 을 누르면 **테넌트 생성** 창이 열립니다.

![테넌트 생성 창 — 이름과 소유자 이메일을 넣은 모습](shots/operator/tenants-2.png){crop=dialog marks=name,slug,owner,check,submit}

1. **이름** 칸에 회사 이름을 입력합니다.
2. **slug (선택)** 칸은 비워 둡니다. 직접 정하려면 영문 소문자·숫자·하이픈으로 입력합니다.
3. **소유자 이메일 (선택)** 칸에 테넌트를 맡을 사람의 이메일을 입력합니다.
4. **확인** 을 누릅니다. 그 이메일의 사용자를 찾으면 이름과 이메일이 카드로 나옵니다.
5. **생성** 을 누릅니다. 테넌트가 목록에 추가됩니다.

slug 는 테넌트를 구분하는 영문 이름입니다. 비워 두면 이름에서 자동으로 만들어집니다. 이름에 영문이 없으면 `tenant`, `tenant-2` 처럼 만들어집니다. 다른 테넌트가 쓰는 slug 는 쓸 수 없습니다.

소유자로 정한 사람은 그 테넌트의 소유자가 되고, 테넌트 관리자 권한을 받습니다. 소유자는 이미 계정이 있는 사람만 정할 수 있습니다. 에이전트나 비활성 계정은 소유자가 될 수 없습니다.

> **참고**
>
> 소유자가 될 사람의 계정이 아직 없으면 **해당 이메일의 사용자가 없습니다.** 로 시작하는 안내가 나옵니다. 소유자 칸을 비우고 테넌트를 만든 뒤, [3장](03-tenant-members.md)의 방법으로 계정을 만들면서 역할을 소유자로 정해 추가합니다.

## 테넌트 상세 화면을 본다

목록에서 테넌트 이름을 누르면 상세 화면이 열립니다. 위에서부터 테넌트 정보, **드라이브 용량 한도 (GB)**, **멤버** 표, **위험 구역** 이 차례로 있습니다.

![테넌트 상세 — 정보 카드와 드라이브 용량 한도](shots/operator/tenants-3.png){crop=card+quota marks=edit,quota}

1. 정보 카드 오른쪽 위의 **편집** 으로 이름과 slug 를 고칩니다(아래 「이름과 slug 를 고친다」).
2. **드라이브 용량 한도 (GB)** 에서 테넌트 드라이브의 용량 한도를 바꿉니다(아래 「드라이브 용량 한도를 바꾼다」).

정보 카드에는 **슬러그**·**상태**·**생성일**·**멤버수** 가 보입니다. **멤버** 표는 [3장](03-tenant-members.md), **위험 구역** 과 **정지** 단추는 [4장](04-tenant-lifecycle.md)에서 다룹니다. **목록으로** 를 누르면 테넌트 목록으로 돌아갑니다.

## 이름과 slug 를 고친다

상세 화면의 **편집** 을 누르면 **테넌트 정보 편집** 창이 열립니다.

![테넌트 정보 편집 창](shots/operator/tenants-4.png){crop=dialog marks=name,slug,save}

1. **이름** 칸의 이름을 고칩니다.
2. **slug** 칸을 고칩니다. 비우면 이름에서 다시 만들어집니다.
3. **저장** 을 누릅니다.

삭제된 테넌트에는 **편집** 이 보이지 않습니다. 고치려면 먼저 복원합니다([4장](04-tenant-lifecycle.md)).

## 드라이브 용량 한도를 바꾼다

드라이브 용량 한도는 그 테넌트가 쓸 수 있는 저장 용량입니다. 드라이브 파일과 노트 첨부 파일이 함께 용량에 들어갑니다. 드라이브 파일은 지난 버전도 들어가고, 휴지통에 있는 파일은 빠집니다. 한도를 넘으면 파일을 더 올릴 수 없고, 휴지통에서 복원해 한도를 넘게 되는 경우에도 복원이 막힙니다.

1. 상세 화면의 **드라이브 용량 한도 (GB)** 칸에 새 한도를 GB 단위로 입력합니다.
2. 칸 옆의 **저장** 을 누릅니다.

삭제된 테넌트는 한도를 바꿀 수 없어 칸과 **저장** 이 흐리게 보입니다.
