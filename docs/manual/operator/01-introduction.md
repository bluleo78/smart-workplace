# 소개와 로그인

Gen:iA Works 를 쓰는 회사 하나하나를 테넌트라고 합니다. 구성원은 사용자 앱에서 자기 테넌트(워크스페이스) 안의 일만 봅니다. 슈퍼어드민은 그 바깥에서 테넌트 전체를 관리하는 플랫폼 운영자입니다. 슈퍼어드민은 사용자 앱과 따로 떨어진 **플랫폼 콘솔** 에서 일합니다.

> **이 장에서 할 수 있는 일**
>
> - 슈퍼어드민이 무엇을 하는지 압니다.
> - 플랫폼 콘솔에 로그인합니다.
> - 콘솔 화면의 구성을 봅니다.
> - 로그아웃하고 테마를 바꿉니다.

## 슈퍼어드민이 하는 일

슈퍼어드민은 플랫폼 콘솔에서 다음 일을 합니다.

| 하는 일 | 다루는 장 |
| --- | --- |
| 테넌트를 만들고 이름·slug·드라이브 용량 한도를 고칩니다 | [2장](02-tenants.md) |
| 테넌트에 구성원을 넣습니다. 이미 있는 계정을 넣거나 새 계정을 만들어 넣습니다 | [3장](03-tenant-members.md) |
| 테넌트를 정지·활성화하고, 삭제·복원·영구 삭제합니다 | [4장](04-tenant-lifecycle.md) |

테넌트 안의 업무 데이터(이슈·메일·드라이브 파일 등)는 콘솔에서 보이지 않습니다. 콘솔의 구성원 목록도 이름과 이메일을 가려서 보여 줍니다([3장](03-tenant-members.md)).

슈퍼어드민 계정은 사용자 앱의 계정과 같은 계정입니다. 서비스를 처음 설치한 뒤 맨 처음 가입한 계정이 슈퍼어드민이 됩니다. 이 계정은 기본 테넌트 「Default Workspace」 의 구성원이기도 합니다.

슈퍼어드민은 이 한 계정뿐입니다. 콘솔의 **운영자** 메뉴는 준비 중이라 콘솔에서 슈퍼어드민을 더 둘 수 없습니다.

## 플랫폼 콘솔에 로그인한다

플랫폼 콘솔은 사용자 앱과 주소가 다릅니다. 로그인 화면 위에 「Platform」 표시와 **플랫폼 콘솔** 제목이 있으면 맞게 들어온 것입니다.

![플랫폼 콘솔 로그인 화면](shots/operator/introduction-1.png){crop=card marks=username,password,submit}

1. **아이디** 칸에 슈퍼어드민 계정의 아이디를 입력합니다.
2. **비밀번호** 칸에 비밀번호를 입력합니다.
3. **로그인** 을 누릅니다. 테넌트 목록이 열립니다.

로그인이 안 되면 화면에 나온 문구로 원인을 구분합니다.

| 문구 | 뜻 |
| --- | --- |
| **아이디 또는 비밀번호가 올바르지 않습니다.** | 아이디나 비밀번호가 틀렸습니다 |
| **운영자 권한이 없습니다.** | 아이디·비밀번호는 맞지만 슈퍼어드민 계정이 아닙니다. 구성원 계정으로는 콘솔에 들어올 수 없습니다 |

> **참고**
>
> 콘솔은 로그인을 기억합니다. 같은 브라우저에서 창을 새로 고치거나 다시 열어도 로그인 화면을 거치지 않고 들어갑니다. 로그인을 끝내려면 아래 「로그아웃한다」를 따릅니다.

## 콘솔 화면을 둘러본다

로그인하면 테넌트 목록이 열립니다. 왼쪽 메뉴에서 화면을 고르고, 메뉴 맨 아래에 로그인한 계정의 이름이 보입니다.

![플랫폼 콘솔 — 왼쪽 메뉴와 테넌트 목록](shots/operator/introduction-2.png){marks=tenants,user}

1. **테넌트** 를 누르면 테넌트 목록으로 돌아옵니다. 콘솔에서 하는 일은 모두 이 메뉴에서 시작합니다.
2. 맨 아래의 계정 이름을 누르면 사용자 메뉴가 열립니다.

메뉴의 **대시보드**·**운영자**·**감사 로그**·**설정** 은 아직 준비 중인 화면입니다. 누르면 **준비중입니다.** 라는 안내만 나옵니다.

## 로그아웃한다

![사용자 메뉴 — 테마 전환과 로그아웃](shots/operator/introduction-3.png){crop=menu+trigger marks=trigger,logout}

1. 왼쪽 맨 아래의 계정 이름을 누릅니다.
2. **로그아웃** 을 누릅니다. 로그인 화면으로 돌아갑니다.

같은 메뉴의 **테마 전환** 을 누르면 밝은 화면과 어두운 화면이 바뀝니다. 메뉴 맨 아래에는 지금 쓰는 콘솔의 버전이 보입니다.
